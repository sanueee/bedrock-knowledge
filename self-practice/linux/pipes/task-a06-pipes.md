## Задание

Написать программу `pipechat` на C.

**Что делает:**
Родитель создаёт дочерний процесс через `fork()`. Дочерний процесс читает строки из stdin и отправляет их родителю через pipe. Родитель получает каждую строку и выводит её с префиксом `[parent received]: `.

**Детали реализации:**
1. Создать pipe через `pipe(fd)` — ДО `fork()`
2. После `fork()`:
   - Дочерний процесс: закрыть `fd[0]` (читающий конец), писать в `fd[1]`
   - Родитель: закрыть `fd[1]` (пишущий конец), читать из `fd[0]`
3. Дочерний читает строки через `fgets()` из stdin, пишет в pipe через `write()`
4. Родитель читает из pipe через `read()` в цикле, выводит результат
5. При EOF (Ctrl+D) — дочерний закрывает `fd[1]`, родитель получает 0 от `read()` и завершается
6. Родитель ждёт дочернего через `waitpid()`

**Функции для использования:**
- `pipe(int fd[2])` — создать pipe
- `fork()` — разделить процесс
- `write(fd, buf, n)` — записать в pipe
- `read(fd, buf, n)` — читать из pipe
- `close(fd)` — закрыть конец pipe (обязательно!)
- `waitpid()` — дождаться дочернего

**Где сохранить:** `self-practice/linux/pipes/pipechat.c`

**Как проверить:**
```
./pipechat
hello       <- вводишь
[parent received]: hello
world       <- вводишь
[parent received]: world
^D          <- Ctrl+D
```

## Ключевые функции

| Функция | Зачем |
|---------|-------|
| `pipe(int fd[2])` | создать pipe: fd[0] — читать, fd[1] — писать |
| `fork()` | разделить процесс на родителя и дочерний |
| `write()` | записать данные в pipe |
| `read()` | читать из pipe, возвращает 0 при EOF |
| `close()` | закрыть ненужный конец — иначе EOF не придёт |
| `waitpid()` | дождаться завершения дочернего |

## Что узнал

- `pipe()` создаёт два файловых дескриптора: `fd[0]` — читать, `fd[1]` — писать
- `pipe()` должен быть до `fork()` — иначе процессы получат разные несвязанные трубы
- Каждый процесс обязан закрыть ненужный конец, иначе EOF никогда не придёт
- `read()` возвращает 0 при EOF — это не ошибка, это сигнал завершения
- `write()` нужно передавать `strlen(buf)`, а не `sizeof(buf)` — иначе шлёшь мусор
- После `read()` нужно ставить нуль-терминатор: `buf[n] = '\0'`
