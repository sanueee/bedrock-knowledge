# Идеально сбалансированные деревья и деревья Фибоначчи

> Две «крайности» по балансу: **идеально сбалансированное** — самое плотное (минимальная
> высота при данном n), **дерево Фибоначчи** — самое разреженное **AVL** (минимум вершин при
> данной высоте, т.е. худший допустимый случай для AVL). Через них выводится оценка высоты AVL.

---

## A. Идеально сбалансированное дерево (perfectly balanced tree)

### 1. Определение
Дерево, у которого **для каждого узла** число вершин в левом и правом поддеревьях различается **не более чем на 1**. (Сильнее, чем AVL, где ограничена разница **высот**, а не числа вершин.)

### 2. Пример (построение)
Из отсортированного массива: корень — **средний** элемент, рекурсивно левую половину → левое поддерево, правую → правое.
```c
Node* build_balanced(int *a, int lo, int hi) {
    if (lo > hi) return NULL;
    int mid = (lo + hi) / 2;
    Node *root = node_new(a[mid]);
    root->left  = build_balanced(a, lo, mid - 1);
    root->right = build_balanced(a, mid + 1, hi);
    return root;
}
```

### 3. Особенности
- Высота **минимально возможная**: `h = ⌊log₂ n⌋`.
- Строится из статического отсортированного набора за O(n); **при вставках/удалениях баланс не держится сам** (нужна перестройка) — поэтому как динамическая структура не используется, её роль — эталон «идеала».

### 4. Плюсы и недостатки
- **+** минимальная высота → минимальное число сравнений при поиске.
- **−** не самоподдерживается при модификациях (в отличие от AVL/КЧ).

### 5. Где применяется
- Построение сбалансированного BST из отсортированного массива (разовая инициализация).
- Эталон для оценки «насколько дерево близко к идеалу».

### 6–7. Операции и сложность
- Поиск O(log n) (высота минимальна). Построение O(n) из сортированного массива.

## B. Деревья Фибоначчи (Fibonacci trees)

### 1. Определение
**Дерево Фибоначчи высоты h** — это **AVL-дерево с минимальным числом вершин** среди всех AVL данной высоты. Это «самый худой» допустимый AVL: ещё чуть разреди — и нарушится AVL-условие.

### 2. Пример / построение (рекурсивное)
Дерево Фибоначчи T(h): корень, левое поддерево — T(h−1), правое — T(h−2) (разница высот ровно 1, максимально допустимая для AVL). База: T(0) — пусто, T(1) — один узел.
```
T(0) = ∅           T(1) = (•)        T(2):   •          T(3):     •
                                            /                    / \
                                          •                  T(2)  T(1)
```

### 3. Особенности — связь с числами Фибоначчи
Минимальное число вершин N(h) в AVL высоты h:
```
N(h) = N(h-1) + N(h-2) + 1,   N(0)=0, N(1)=1
```
Это сдвинутая последовательность Фибоначчи: **N(h) = F(h+2) − 1**, где F — числа Фибоначчи (1,1,2,3,5,8,…). Отсюда узлов: 0,1,2,4,7,12,20,… для h=0,1,2,3,4,5,6.

### 4. Плюсы и недостатки
- Это не структура «для работы», а **теоретический инструмент** — даёт нижнюю границу плотности AVL и верхнюю границу его высоты.

### 5. Где применяется
- **Вывод оценки высоты AVL** (см. §7). Похожая идея в анализе **фибоначчиевых куч** (Fibonacci heap) — там Фибоначчи ограничивает степень узлов.

### 6–7. Главное — оценка высоты AVL

Из `N(h) = F(h+2) − 1` и роста Фибоначчи `F(h) ≈ φ^h/√5` (φ = (1+√5)/2 ≈ 1.618):
```
n ≥ N(h) = F(h+2) − 1  ≈  φ^(h+2)/√5
⇒ h ≤ log_φ(n)  ≈  1.4404 · log₂ n
```
**Вывод:** высота AVL-дерева с n узлами не превышает ≈ **1.44·log₂ n** → поиск/вставка/ удаление O(log n). Дерево Фибоначчи — тот самый случай, который этой границы **достигает** (самый высокий AVL при данном n).

```
Сравнение «крайностей» баланса:
идеально сбалансированное:  h = log₂ n         (плотнее некуда)
дерево Фибоначчи (худший AVL): h ≈ 1.44·log₂ n (разреженнее AVL быть не может)
вырожденное (список):        h = n − 1         (не AVL вообще)
```

## Сквозные темы
- **Вероятностный/асимптотический анализ:** золотое сечение φ как основание роста Фибоначчи → логарифмическая граница высоты. Связь дискретной рекурренты с замкнутой формулой.

## Параллели и trade-offs
- **Идеально сбалансированное vs AVL:** идеальное ограничивает **число вершин** поддеревьев, AVL — **высоты** (слабее, зато поддерживается динамически вращениями).
- **Дерево Фибоначчи vs полное дерево:** два полюса AVL — минимум вершин (Фибоначчи) и максимум (полное двоичное), высоты ≈1.44·log₂n и log₂n соответственно.

## Ключевые термины (English)
- **perfectly balanced tree** — идеально сбалансированное дерево.
- **Fibonacci tree** — дерево Фибоначчи.
- **minimum-node AVL tree** — AVL с минимумом вершин (= дерево Фибоначчи).
- **golden ratio φ** — золотое сечение (основание роста, ≈1.618).
- **height bound h ≤ 1.44·log₂ n** — граница высоты AVL.
