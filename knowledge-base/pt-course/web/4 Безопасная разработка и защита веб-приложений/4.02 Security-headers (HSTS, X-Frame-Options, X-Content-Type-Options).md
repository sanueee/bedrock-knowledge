# Security-headers (HSTS, X-Frame-Options, X-Content-Type-Options)

> [!info] Путь в курсе
> Глава 4: Веб-приложения и безопасность веб-приложений / Часть 4: Безопасная разработка и защита веб-приложений

## Что такое защитные HTTP-заголовки

**Защитные HTTP-заголовки** - это специальные директивы, которые веб-сервер передаёт браузеру клиента для включения встроенных механизмов безопасности. Они не изменяют содержимое страницы, но инструктируют браузер, как именно следует обрабатывать полученные ресурсы. Правильная настройка этих заголовков существенно снижает риск широкого спектра атак.

### X-Frame-Options

Заголовок **X-Frame-Options** предотвращает использование страницы во фреймах. Это защищает от **Clickjacking** - атаки, при которой специалист по анализу защищенности размещает прозрачный фрейм с целевым сайтом поверх обманной кнопки на своём ресурсе. Пользователь нажимает на элемент, но на деле взаимодействует с чужим сайтом.

Рассмотрим простой пример, чтобы разобраться. Есть страница, на которой поверх кнопки "Выиграть приз" размещается абсолютно прозрачный **iframe**, ведущий на страницу банка с кнопкой "Перевести 1000 ₽". Если жертва авторизована в банке и нажимает на видимую кнопку, фактически она нажимает на скрытую кнопку перевода. Заголовок **X-Frame-Options** с соответствующим значением запрещает браузеру отображать страницу внутри фрейма, блокируя эту атаку.

> **iframe** - это HTML-элемент, который позволяет встроить одну веб-страницу внутрь другой.

**Синтаксис и значения**

Заголовок **X-Frame-Options** имеет несколько допустимых значений: **DENY** - полностью запрещает отображение страницы в любом фрейме, даже на том же сайте, **SAMEORIGIN** - разрешает встраивание только внутри фреймов с тем же источником (совпадающие протокол, домен и порт), и значение **ALLOW-FROM uri** - страница может быть встроена только с указанного источника, но современными браузерами это значение игнорируется.

Для большинства сайтов рекомендуется использовать **SAMEORIGIN**. Это позволяет встраивать страницы в собственные фреймы, но запрещает встраивание со сторонних сайтов.

### X-Content-Type-Options

Заголовок **X-Content-Type-Options** запрещает браузеру самому определять MIME-тип ресурса, если сервер указал его неверно или не указал вовсе. Без этого заголовка браузер может самостоятельно определить тип содержимого по его содержимому и обработать его иначе, чем предполагал разработчик.

> **MIME-тип** - это стандартный идентификатор формата данных, который сообщает браузеру, как именно нужно интерпретировать и отображать полученный файл.

Например, специалист по анализу защищенности может загрузить на сервер текстовый файл **script.txt**, но сервер отдаёт его с типом **text/plain**. Без защиты браузер может распознать в содержимом валидный JavaScript и выполнить его как скрипт, что приводит к XSS-атаке.

**Синтаксис и значения**

Заголовок **X-Content-Type-Options** может принимать только одно значение - **nosniff**. При его указании браузер обязан строго следовать MIME-типу, переданному в заголовке **Content-Type**, и не угадывать тип содержимого по его содержимому. Использовать заголовок настоятельно рекомендуется для всех веб-приложений. Он не влияет на обычную работу сайта, но блокирует опасный класс атак, связанных с подменой типа ресурсов.

### HSTS (HTTP Strict Transport Security)

HSTS - это механизм, который заставляет браузер подключаться к сайту только по защищённому протоколу HTTPS, даже если пользователь ввёл **http://** в адресной строке или перешёл по обычной ссылке. Заголовок действует не на один сеанс, а на длительный период. Без HSTS возможна атака понижения протокола. Специалист по анализу защищенности, находящийся в той же сети, перехватывает первый HTTP-запрос пользователя и вместо перенаправления на HTTPS отдаёт поддельную страницу. HSTS предотвращает это, так как браузер, однажды получив заголовок, самостоятельно переходит на HTTPS на указанный срок, даже не отправляя HTTP-запрос.

**Синтаксис и значения**

`Strict-Transport-Security: max-age=<seconds>; includeSubDomains; preload`

- **max-age **- обязательный параметр. Время в секундах, в течение которого браузер должен запомнить политику.
- **includeSubDomains** - распространяет политику на все поддомены текущего домена.
- **preload** - указывает, что владелец сайта согласен на включение домена в список предварительной загрузки HSTS, который жёстко зашит в браузере.

### Заключение

Настройка защитных HTTP-заголовков - это крайне эффективная мера повышения безопасности веб-приложения. Заголовок **X-Frame-Options** защищает пользователей от атак **Clickjacking**, запрещая встраивание страницы во внешние фреймы. Заголовок **X-Content-Type-Options** предотвращает выполнение вредоносного кода, загруженного под видом безобидных текстовых файлов. Заголовок **Strict-Transport-Security** принудительно переводит всё взаимодействие с сайтом на защищённый протокол HTTPS, исключая саму возможность атак понижения протокола.
