## Что такое Directory Traversal

**Directory Traversal **- уязвимость, позволяющая специалисту по анализу защищенности читать, удалять, создавать, а в некоторых случаях и изменять произвольные файлы на сервере, находящемся за пределами корневой папки веб-приложения. Это может включать в себя: код приложения, учетные данные, файлы, содержащие конфиденциальные данные.

## Как устроена уязвимость

Веб-сайты сегодня состоят из множества компонентов, таких как изображения, видео, CSS- и JavaScript-файлы. Эти ресурсы подключаются в HTML-документе и загружаются браузером отдельными HTTP-запросами.

Существуют два основных способа работы с такими файлами: **статическая** и **динамическая** загрузка.

- **При статической загрузке** путь к файлу заранее определен в коде приложения (или отдается напрямую веб-сервером, например, Nginx/Apache), и пользователь никак не влияет на его формирование. Такие ресурсы находятся в фиксированных местах и просто запрашиваются по заданным ссылкам.
- **При динамической загрузке** путь к файлу формируется во время выполнения программы, часто на основе данных, полученных от пользователя. Разработчики нередко реализуют обработку файлов внутри определенных изолированных директорий. Например, веб-приложение может хранить изображения пользователей в каталоге **/var/www/app/images/** и предоставлять к ним доступ через скрипт-обработчик.
   Так, например, есть веб-приложение для хранения файлов:

![](../../_images/4b0cb261cb81.webp)

Легитимный запрос к файлу **example_file1.txt** выглядит следующим образом: `http://example.com/file?name=example_file1.txt`

Однако, если специалист по анализу защищенности изменит значение параметра, добавив в него последовательности **../**, запрос примет следующий вид: `http://example/file?name=../../../../user/secret.txt`

Если разработчик не предусмотрел надежную фильтрацию, серверная логика выполняет конкатенацию базовой директории приложения с переданным путем. Операционная система при обработке полученного пути интерпретирует каждую конструкцию **../** как переход в родительский каталог. В результате специалист может получить содержимое файла **secret.txt.**

![](../../_images/4e02f8c11479.webp)

Часто разработчики пытаются устранить уязвимость Directory Traversal, но делают это недостаточно корректно, в результате возможность эксплуатации остаётся. Так, например, разработчики могут просто удалять последовательности вроде **../** из строки запроса. Однако такой подход легко обходится, например, через **....//**. Также встречаются ситуации, когда веб-приложение удаляет любые последовательности обхода каталога. Иногда можно обойти этот вид очистки с помощью URL-кодирования.

В контексте тестирования специалист может получить доступ к:

**системным файлам операционной системы:**

- **/proc/self/environ**
- **/etc/passwd**
- **/etc/hosts**
- **C:\Windows\win.ini**

**конфигурационным файлам приложений и веб-серверов, или журналам событий:**

- **.env**
- **config.php**
- **web.config**
- **/var/log/apache2/access.log**

**служебным данным и артефактам git:**

- **git/config**
- **.git/HEAD**
- **.git/index**
- **.git/objects/**

## Последствия эксплуатации уязвимости

Эксплуатация уязвимости **Directory Traversal** приводит к нарушениям конфиденциальности и создает предпосылки для компрометации инфраструктуры. Первичным следствием является несанкционированное чтение системных файлов, исходного кода и конфигураций, что влечет за собой утечку учетных данных. Это обеспечивает пользователю возможность перемещения по сети и эскалации привилегий.

## Инструменты, используемые атакующими для обнаружения и последующей эксплуатации Directory Traversal

- [**Burp Suite**](https://portswigger.net/burp) - один из наиболее распространённых инструментов для тестирования безопасности веб-приложений. Используется для перехвата, изменения и анализа HTTP-запросов, а также автоматизированного поиска различных уязвимостей, включая Directory Traversal.
- [**Gobuster **](https://github.com/Oj/gobuster)- инструмент для перебора директорий и файлов на веб-серверах, который часто используется для поиска скрытых путей и потенциальных уязвимостей Directory Traversal.
- [**brainstorm **](https://github.com/brainstorm-tools/brainstorm3)- интеллектуальный инструмент для веб-фаззинга, использующий локальные LLM-модели (например, через Ollama) для более “умного” анализа возможных уязвимостей.
- [**Dirb **](https://github.com/ct-Open-Source/dirb)- простой и быстрый сканер, предназначенный для поиска скрытых директорий и файлов на веб-сайтах.
- [**Dirbuster** ](https://dirbuster.com/)- графическая утилита от OWASP для перебора директорий и файлов, применяемая для обнаружения скрытых и потенциально уязвимых ресурсов.
- [**ffuf**](https://github.com/ffuf/ffuf) - высокопроизводительный инструмент для фаззинга веб-приложений, который также может использоваться для поиска уязвимых путей, включая Directory Traversal.
- [**dirsearch**](https://github.com/maurosoria/dirsearch) - консольная утилита для автоматизированного сканирования веб-серверов с целью поиска скрытых директорий и файлов.
