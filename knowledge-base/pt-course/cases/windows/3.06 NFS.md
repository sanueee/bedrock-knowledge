## Стенд / введение

Для выполнения данного кейса необходимо скачать [**OVA-образ**](https://storage.ptsecurity.com/seafhttp/f/cc138432c0754faab4d5/?op=view) виртуальной машины, заготовленной Positive Technologies. У данной виртуальной машины должен быть 1 сетевой адаптер VirtualBox в режиме bridge. Также понадобится **Debian** как сервер **nfs**

К виртуальной машине можно подключиться с помощью графического интерфейса VirtualBox со следующими учётными данными:

**Windows VM:**

- Login - **admin**
   
   - Password - **admin**
- Login - **student**
   
   - Password - **student**

**Цель практики:** Научиться работать с NFS

**NFS клиент windows**

Используем виртуальную машину Windows

Запускаем powershell от имени администратора

![](../../_images/77d298e32ae2.jpg)

Для установки требуются 2 компонента:

- **ServicesForNFS-ClientOnly** - основной клиент NFS
- **ClientForNFS-Infrastructure** - управление NFS

Для их установки воспользуемся командой: `Enable-WindowsOptionalFeature -FeatureName ServicesForNFS-ClientOnly, ClientForNFS-Infrastructure -Online -NoRestart`

После выполним перезагрузку компьютера

![](../../_images/b5098c15ef2b.webp)

Скачиваем на linux **nfs**. Команда: `sudo apt install nfs-kernel-server nfs-common -y`

![](../../_images/089a704e0bde.jpg)

Cоздадим **NFS** папку и настроим владельца и права на папку

- Создание: `mkdir -p /srv/ShareWin`
- Назначение пользователя **nobody **владельцем папки: `sudo chown nobody:nogroup /srv/ShareWin`
- Даём всем полные права на папку: `sudo chmod 777 /srv/ShareWin`
- проверим владельца и права: `ls -l /srv`

![](../../_images/4ec5dc4236b7.jpg)

Настраиваем сам nfs. Откроим файл **/etc/exports**. Команда: `sudo nano /etc/exports` и добавим в него одну строку: `/srv/ShareWin *(rw,sync,subtree_check,fsid=0)` после сохраним файл

![](../../_images/2c7fc192dcea.jpg)

> **/srv/ShareWin** - указываем сетевую папку
> 
> 
> 
> ***** Разрешаем доступ всем в сети(обычно указывается ip-адрес)
> 
> 
> 
> **(rw,sync,no_subtree_check,no_root_squash,fsid=0)** - параметры:
> 
> 
> 
> **rw** - клиенты могут читать и писать в папку
> 
> 
> 
> **sync** - Запись на диск происходит **синхронно** (сервер подтверждает операцию только после реальной записи)
> 
> 
> 
> **subtree_check** - заставляет сервер NFS проверять, что каждый запрашиваемый файл физически находится внутри экспортируемой папки
> 
> 
> 
> **fsid=0** - помечаем главную точку монтирования ShareWin

Применим настройки:

```
sudo exportfs -a
sudo systemctl restart nfs-server
```

![](../../_images/e89b2ccfd964.jpg)

На Windows машине переходим в мой компьютер, нажимаем **...** и выбираем **Map network drive**

![](../../_images/509ceec615c3.webp)

Вписываем адрес сетевой папки linux машины

![](../../_images/b3a68a94c47f.webp)

Теперь мы можем зайти в сетевую папку и создать файл **test **с расширением** txt**

> На скриншоте в проводнике включено расширение файлов. Для включения данной функции вы можете нажать в проводнике "View" - "Show" - "File name extensions"

![](../../_images/2dbc5b724221.webp)

На linux мы увидим созданный файл **ls**

![](../../_images/d22ef022551d.jpg)
