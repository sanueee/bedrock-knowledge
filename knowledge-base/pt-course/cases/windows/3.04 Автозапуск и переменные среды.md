## Стенд / введение

Для выполнения данного кейса необходимо скачать [**OVA-образ**](https://storage.ptsecurity.com/seafhttp/f/cc138432c0754faab4d5/?op=view) виртуальной машины, заготовленной Positive Technologies. У данной виртуальной машины должен быть 1 сетевой адаптер VirtualBox в режиме bridge.

К виртуальной машине можно подключиться с помощью графического интерфейса VirtualBox со следующими учётными данными:

**Windows VM:**

- Login - **admin**
   
   - Password - **admin**
- Login - **student**
   
   - Password - **student**

**Цель практики:** Научиться управлять переменным окружением и автозапуском

### Автозапуск и управление переменными окружения

Создадим **auth.bat** на рабочем столе. В нем напишем:

```
@echo off
if %1==1 set LOGIN=user1&set PASSWORD=pass123
if %1==2 set LOGIN=ivan&set PASSWORD=qwerty
echo %LOGIN% %PASSWORD%
```

![](../../_images/e93facf40940.jpg)

Зайдем в **System Properties**. Нажмём **Win+R** и введём: `sysdm.cpl`

![](../../_images/f33a1d0daf49.webp)

переходим в **Advanced** и нажимаем **Environment Variables...**

![](../../_images/89fb399638ed.jpg)

В **User variables for admin** нажимаем **New...**

![](../../_images/c7cef8ad6e37.webp)

Копируем полный путь **auth.bat** (правой кнопкой по файлу - **copy as path**)

![](../../_images/8c004ee84eba.webp)

Пишем в **name** - `auth`, **value** - скопированный путь до файла

![](../../_images/18efe72c94f7.webp)

после добавления не забываем нажать **OK**

![](../../_images/867af6eacd62.webp)

проверим в **cmd** введя: `%auth% 1`

> Переменная окружения позволяет вызывать скрипты по короткому имени из любого места не задавая полного пути.

![](../../_images/0f86dd0f1366.webp)

нажимаем **Win+R** и для открытия папки с автозапуском вводим: `shell:startup`

![](../../_images/f32f544d7541.jpg)

Загрузим файл по ссылке в папку [**auth_manager.bat**](https://storage.ptsecurity.com/seafhttp/f/f47c732f52ff4b308ebb/?op=view)

![](../../_images/ebed1e6242eb.webp)

Далее проверим что скрипт запускается при каждом включении системы. Для этого перезайдём в аккаунт или перезапустим систему

![](../../_images/4a695c3b00bb.webp)

При старте нас будет ожидать окно для работы с **auth.bat**

![](../../_images/d6f6d83f09e0.webp)
