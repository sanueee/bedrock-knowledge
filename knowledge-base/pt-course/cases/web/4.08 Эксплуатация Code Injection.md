## Стенд / введение

- Для выполнения кейса скачайте [**Ova-образ**](https://storage.ptsecurity.com/seafhttp/f/aedb0743eb174814a4da/?op=view) виртуальной машины. В образе уже предустановлено всё необходимое ПО, веб-приложение запущено и работает на сетевом порту 5000
- Для доступа к виртуальным машинам с хост-машины настроен проброс портов в **VirtualBox**. Доступ к веб-приложению осуществляется через обращение к **http://localhost:5000**

Начнем анализ веб-приложения. Для этого перейдем по адресу** http://127.0.0.1:5000**. Нас встречает домашняя страница сервиса финансового учета.

![](../../_images/3dbe7d8d805c.webp)

В процессе анализа можем увидеть страницу, в которой идет учет всех транзакций, и для каждого поступления учитывается налоговая ставка

![](../../_images/fd994c0855fe.webp)

В настройках приложения предусмотрена возможность модификации формулы расчёта налога. Подобный функционал потенциально уязвим, поскольку механизм вычисления пользовательских выражений часто реализуется через динамическую интерпретацию кода. В таких случаях строка, введённая пользователем, фактически превращается в исполняемый код. Если на пути от ввода до интерпретатора отсутствуют механизмы санитизации, возникает возможность внедрить произвольные команды, выходящие за рамки математических вычислений, и выполнить их в контексте серверного приложения.

После выявления возможности редактирования формулы вычисления проверим наличие уязвимости внедрения кода. Сформируем полезную нагрузку вида: `__import__('os').popen('ls').read()`

Рассмотрим механизм работы данной конструкции.

**__import__('os')** - функция Python, предназначенная для динамического импорта модулей по строковому имени. В отличие от стандартного оператора import, функция **__import__** может быть вызвана как обычное выражение, возвращающее объект модуля, что делает её пригодной для внедрения в контекст вычисления формулы. В данном случае импортируется модуль **os. **Далее вызывается метод модуля **os**, который запускает указанную команду оболочки. В данном случае это команда **ls**. После вызывается метод **read()**. Данный метод считывает весь доступный вывод команды в строку. Без вызова **read()** результатом выражения был бы дескриптор процесса, а не сами данные.

![](../../_images/21c760ba66d6.webp)

В результате на главное странице вместо суммы налога, увидим содержание текущей директории.
