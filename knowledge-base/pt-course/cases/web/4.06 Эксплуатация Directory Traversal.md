# Guided Case 4.6 — Эксплуатация Directory Traversal

## Стенд / введение

- Для выполнения кейса скачайте [**OVA-образ**](https://storage.ptsecurity.com/seafhttp/f/31aa459c0f85460da294/?op=view) виртуальной машины. В образе уже предустановлено всё необходимое ПО, веб-приложение запущено и работает на сетевом порту 5000.
- Для доступа к виртуальным машинам с хост-машины настроен проброс портов в **VirtualBox**. Доступ к веб-приложению осуществляется через обращение к **http://localhost:5000**. Для входа в приложение используйте:
   
   - Логин - **edtechlab_user**
   - Пароль - **12345**

Мы разобрали, как с помощью последовательности **../** можно выйти за пределы разрешённой директории и получить доступ к файлам на сервере. В качестве примера рассмотрим файловое хранилище **FileVault**. Запустим виртуальную машину. Веб-приложение уже работает, запускать ничего не нужно. Откроем в браузере **http://127.0.0.1:5000** и войдём под пользователем **edtechlab_user** с паролем **12345** и изучим функционал веб-приложения.

![](../../_images/70b33be47db1.webp)

На главной странице список файлов, у каждого указаны размер и дата, рядом действия **View**, **Download** и **Delete**. Слева меню с созданием файла и просмотром всех файлов, ниже виджет занятого места.

![](../../_images/cd7973b55c3c.webp)

Откроем один из файлов через **View** и посмотрим на адресную строку.

![](../../_images/449ebe5beb6d.webp)

Видим, что файл запрашивается по параметру **name**. Раз приложение обращается к файлу по имени из адреса, проверим, ограничено ли оно нашей папкой. Попробуем выйти за её пределы, подставив в начало имени последовательность **../**, которая означает переход на каталог выше. Запросим `?name=../budget-2026.csv`.

![](../../_images/4cf667b08038.webp)

Файл открывается, хотя такой путь должен был увести на уровень выше хранилища. Вероятнее всего в приложении стоит фильтр, который вырезает **../** из имени, поэтому после очистки остаётся **budget-2026.csv** и файл открывается. Проверим альтернативные варианты полезных нагрузок, например, `?name=....//budget-2026.csv`. Теперь файл не открывается.

![](../../_images/73d51108bc56.webp)

Фильтр вырезал **../** из середины последовательности **....//**, но из оставшихся символов снова сложилось **../budget-2026.csv**, что уводит за пределы хранилища. Вероятнее всего, фильтр срабатывает лишь один раз, поэтому и обходится такой конструкцией.

## Вопрос №1
*тип: open_answer, макс. баллов: 1, попыток: 3*

Обойдите фильтр и прочитайте конфигурационный файл **config.txt**, расположенный за пределами хранилища. Какой **INTERNAL_TOKEN** в нём указан? Пример: **a1B2c3D4e5F6g7H**

А можем ли мы создавать файлы за пределами веб-приложения? Судя по тому, что файл удалось прочитать за пределами хранилища, можно предположить, что **Directory Traversal** позволит и создать файл за его пределами. Для проверки перейдем во вкладку **New File**.

## Вопрос №2
*тип: open_answer, макс. баллов: 1, попыток: 3*

Создайте файл, который запишется за пределы хранилища. Если это удастся, приложение выдаст флаг. Какой **флаг** вы получили? Пример: **a1B2c3D4e5F6g7H**
