# Self-study Case 2.17 — Password Spraying

> [!info] Путь в курсе
> Глава 2: Сети и сетевая безопасность / Часть 3. Кибератаки и защита от них / Атака методом подбора

## Стенд / введение

Создадим виртуальную инфраструктуру в соответствии с схемой ниже:

![](../../_images/6174f639e97a.webp)

Первая сеть **192.168.1.0/24**, которая состоит из:

1. Маршрутизатором выступает **OPNsense** с интерфейсом **em1**:
   
   - IP-адрес - 192.168.1.1
   - Маска - 255.255.255.0
2. **Debian-машина** с интерфейсом **enp0s3**
   
   - IP-адрес - назначается по DHCP
   - Маска - назначается по DHCP
   - Сетевой шлюз - 192.168.1.1

Вторая сеть **192.168.2.0/24** состоит из:

1. **OPNsense** с интерфейсом **em2**:
   
   - IP-адрес - 192.168.2.1
   - Маска - 255.255.255.0
2. **FTP Server** с интерфейсом **enp0s3**     - IP-адрес - назначается по DHCP
   
   - Маска - назначается по DHCP
   - Сетевой шлюз - 192.168.2.1

Выход в внешнюю сеть на **OPNsense**:

- IP-адрес - назначается DHCP по сетевому мосту
- Маска - назначается по DHCP

Для выполнения данного кейса необходимо скачать **OVA-образ** виртуальной машины **FTP Server**, заготовленный Positive Technologies, скачать его можно по [**данной ссылке**](https://storage.ptsecurity.com/seafhttp/f/83dda504a26d44ed98d7/?op=view). **FTP Server** уже настроен, требуется только подключить с правильными сетевыми параметрами

Также необходимо скачать следующие файлы:

- [**файл с логинами**](https://storage.ptsecurity.com/seafhttp/f/5dca6673457f4bbd8d00/?op=view)
- [**файл с паролями**](https://storage.ptsecurity.com/seafhttp/f/f3045498545f4ad48f43/?op=view)

> У виртуальных машин из подсетей 192.168.0.1/24 и 192.168.0.1/24 должно быть по 1 сетевому адаптеру VirtualBox в режиме **Internal Network**

Настроим OPNsense на работу и детектирование, как это указано в разделе **настройки межсетевого экрана OPNsense**. В OPNsense есть встроенные механизмы для детектирования и предотвращения атак - интегрирована **Suricata**. Имеется база готовых сигнатур для обнаружения атак. Для нашей задачи нужно установить правила **ET open/emerging-scan** и **ET open/emerging-ftp**, затем подключить их для детектирования атаки.

> **Suricata** - это высокопроизводительная система обнаружения и предотвращения вторжений с открытым исходным кодом.

## Вопрос
*тип: open_answer, макс. баллов: 2, попыток: 3*

Необходимо ответить на 2 вопроса:

**Подвопрос 1.** Какой **пароль** указан в файле readme.txt? Пример ответа: **1234**

**Подвопрос 2.** Какой **флаг** находится в файле key.txt на ftp сервере (key:**указан ключ**)? Пример ответа: **12gree@few234$**
