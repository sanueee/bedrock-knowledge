# Guided Case 2.16 — Brute Force Telnet

> [!info] Путь в курсе
> Глава 2: Сети и сетевая безопасность / Часть 3. Кибератаки и защита от них / Атака методом подбора

## Стенд / введение

Создадим виртуальную инфраструктуру в соответствии с схемой ниже:

![](../../_images/bbc332bc0d31.webp)

Есть одна сеть **192.168.1.0/24**, в которой находятся 2 виртуальные машины:

1. маршрутизатор **MikroTik** с интерфейсом **ether1**:
   
   - IP-адрес - 192.168.1.1
   - Маска - 255.255.255.0
2. **Debian-машина** с интерфейсом **enp0s3**:
   
   - IP-адрес - получен DHCP
   - Маска - получен DHCP
   - Сетевой шлюз - 192.168.1.1

Для выполнения данного кейса необходимо скачать **OVA-образ** виртуальной машины **MikroTik**, заготовленной Positive Technologies, по [**данной ссылке**](https://storage.ptsecurity.com/seafhttp/f/21e1a5edda2b40b791c7/?op=view). В данной инфраструктуре маршрутизатор уже настроен, при разворачивание машины **сохраняйте все конфигурации сетевого оборудования**

Также необходимо скачать следующие файлы:

- [**файл с логинами**](https://storage.ptsecurity.com/seafhttp/f/5dca6673457f4bbd8d00/?op=view)
- [**файл с паролями**](https://storage.ptsecurity.com/seafhttp/f/f3045498545f4ad48f43/?op=view)

> У всех виртуальных машин должно быть по **1** сетевому адаптеру VirtualBox в режиме **Internal Network**

После подключения и развертывания виртуальной машины проверим, какие сетевые службы подняты командой `sudo nmap -sS 192.168.1.1`.

![](../../_images/affecb2be91d.webp)

Как видно, при сканировании 1000 популярных портов у нас поднята только служба telnet.

В нынешних реалиях редко кто открывает возможность подключения по telnet, так как он не является криптографически защищенным протоколом и весь трафик проходит в открытом виде. Чаще всего telnet отключен в стартовой конфигурации работы маршрутизаторов, но тут он открыт. Попробуем провести атаку методом перебора, так как могут стоять дефолтные логины и пароли от системы.

Используем **Medusa** для перебора, установив утилиту командой **sudo apt install Medusa**. Воспользоваться Medusa можно следующим образом: `medusa -h 192.168.1.1 -U log.txt -P passwords.txt -M telnet -v 4 -t 1` где:

- -h - IP-адрес или имя целевого хоста
- -U - текстовый файл со списком логинов
- -P - текстовый файл со списком паролей
- -M - имя подключаемого модуля протокола (в данном случае telnet)
- -v - уровень детализации логов (значение 4 выводит максимум информации)
- -t - количество одновременно работающих потоков

> **Medusa** - это высокоскоростной, модульный инструмент для брутфорса сетевых служб

> **Brute force** - это метод взлома, при котором злоумышленник пытается найти логин, пароль, PIN-код или ключ шифрования, **перебирая все возможные комбинации символов**

## Вопрос
*тип: open_answer, макс. баллов: 3, попыток: 3*

С помощью техники перебора нужно ответить на следующие вопросы:

**Подвопрос 1.** Какой ник у пользователя, который имеет доступ по telnet? Пример: **admin**

**Подвопрос 2.** Какой пароль у пользователя, который имеет доступ по telnet? Пример: **admin**

**Подвопрос 3.** Какой ключ в заголовке после входа по telnet висит в шапке (key:**указан ключ**)? Пример: **key**
