# Guided Case 2.4 — Статическая маршрутизация

> [!info] Путь в курсе
> Глава 2: Сети и сетевая безопасность / Часть 2. Методы конфигурации сети / Маршрутизация

## Стенд / введение

Создадим виртуальную инфраструктуру в соответствии со схемой ниже:

![](../../_images/15afaa6929f4.webp)

**Виртуальная инфраструктура состоит из:**

1. Маршрутизатора **MikroTik1** c адресом 192.168.1.1/24 внутри сети с Debian1 и адресом 10.0.0.1/30 внутри сети с **MikroTik2**
2. Маршрутизатора **MikroTik2** c адресом 192.168.2.1/24 внутри сети с Debian2 и адресом 10.0.0.2/30 внутри сети с **MikroTik1**
3. Debian-машина **Debian1** с адресом 192.168.1.10/24 и шлюзом 192.168.1.1
4. Debian-машина **Debian2** с адресом 192.168.2.10/24 и шлюзом 192.168.2.1

Для выполнения данного кейса необходимо скачать новый или клонировать ранее скачанный **OVA-образ** виртуальной Debian-машины, заготовленной Positive Technologies. В данном образе уже есть предустановленный набор программного обеспечения, а скачать его можно по [**данной ссылке**](https://storage.ptsecurity.com/seafhttp/f/b4275685f64849189a2a/?op=view)

Для начала добавим новый второй интерфейс **ether2 **(Internal network) каждому устройству **MikroTik** в настройках VirtualBox. Его мы будем использовать для связки двух маршрутизаторов.

Теперь настроим сетевые интерфейсы на **MikroTik1**, используя следующие команды:

1. `/ip address add address=192.168.1.1/24 interface=ether1` - назначает адрес 192.168.1.1/24 на интерфейс ether1.
2. `/ip address add address=10.0.0.1/30 interface=ether2` - назначает адрес 10.0.0.1/30 на интерфейс ether2.

Затем аналогично выставим следующие настройки для интерфейсов устройства **MikroTik2**

1. `/ip address add address=192.168.2.1/24 interface=ether1` - назначает адрес 192.168.2.1/24 на интерфейс ether1.
2. `/ip address add address=10.0.0.2/30 interface=ether2` - назначает адрес 10.0.0.2/30 на интерфейс ether2.

Для хостов **Debian1** и **Debian2** назначим соответствующие IP-адреса в конфигурационных файлах:

1. Debian1 - **192.168.1.10/24**
2. Debian2 - **192.168.2.10/24**

С помощью команды `/ip route add dst-address=192.168.2.0/24 gateway=10.0.0.2` создадим маршрут на MikroTik1 из сети **192.168.1.0** в **192.168.2.0**

Теперь воспользовавшись командой `/ip route add dst-address=192.168.1.0/24 gateway=10.0.0.1` создадим маршрут на MikroTik2 из сети **192.168.2.0** в **192.168.1.0**

Если при настройке IP-адресов была допущена ошибка, просмотреть созданные записи можно с помощью команды: `/ip address print`

Каждой записи в выводе будет присвоен номер. Чтобы удалить ошибочную запись, укажем её номер в команде **remove**. Например: `/ip address remove 2`

Также можно удалить несколько записей одновременно: `/ip address remove 2,3,4`

После этого необходимые IP-адреса можно добавить повторно. Для удобства работы с терминалом MikroTik можно использовать сочетание **Ctrl+L** или клавишу **F5** – они перерисовывают экран терминала, убирая предыдущий вывод с экрана. По назначению это похоже на использование команды **clear** в Linux.
