# Настройка межсетевого экрана OPNsense

> [!info] Путь в курсе
> Глава 2: Сети и сетевая безопасность / Часть 3. Кибератаки и защита от них

## 1) Создание виртуальной машины в VirtualBox

Скачаем установочный образ amd64 по [**данной ссылке**](https://pkg.opnsense.org/releases/26.1.6/OPNsense-26.1.2-dvd-amd64.iso.bz2)

Перейдем на главную страницу VirtualBox и создадим виртуальную машину, для этого нажмём на кнопку **New**:

![](../../_images/54c52fb21758.webp)

Выставим следующие параметры:

1. **VM Name** - имя **OPNsense-Gold**
2. **VM Folder** - выставляем удобный для себя путь для файлов нашей виртуальной машины, к примеру, **C:\PT_EdTechLab\VirtualBox**
3. **ISO Image** - ставим путь до скачанного ISO образа машины, например, *C:\PT_EdTechLab\ISO*
4. **OS** - выбираем ОС **BSD**
5. **OS Distribution** - выставляем дистрибутив **FreeBSD**
6. **OS Version** - ставим версию ОС **FreeBSD (64-bit)**

Убираем галочку с автоустановкой

![](../../_images/20cd92f47bbb.webp)

Выставим настройки аппаратного обеспечения:

- **Base Memory** - 4096 MB
- **Num of CPU** - 2 CPU

![](../../_images/8e5cbf5739df.webp)

Выставим **Disk Size** - 16 GB

Проверяем итоговые настройки системы и жмем на **Finish**

![](../../_images/81b405671588.webp)

Выбираем тип сетевого адаптера **bridged adapter** для первого сетевого интерфейса, с доступом в сеть. Для второго и третьего интерфейса ставим **internal Network**.

![](../../_images/7168d07576d9.webp)

> По умолчанию интерфейсу LAN в OPNsense может быть назначен адрес **192.168.1.1/24**. Если интерфейс WAN, подключённый через сетевой мост, также получает адрес из сети **192.168.1.0/24**, подсети WAN и LAN пересекутся, из-за чего веб-интерфейс может стать недоступен. В таком случае назначьте LAN адрес из другой подсети, например **192.168.10.1/24**

В настройках машины переходим в настройки параметров **System** и ставим оптический диск на первое место в порядке загрузки. Дальше выбираем чипсет **ICH9** и версию TPM - **2.0**.

![](../../_images/7bb1b25d8213.webp)

Для дальнейшей установки системы нужно запустить виртуальную машину. Нажимаем на зеленую стрелку:

![](../../_images/d523d321bda2.webp)

## 2) Установка OPNsense

После загрузки виртуальной машины для установки OPNsense нужно войти с этими учетными данными:

- login - **installer**
- password - **opnsense**

![](../../_images/d6a5eba67a29.webp)

После входа появится установщик, выбираем **Continue with default keymap**, нажав **Enter**

![](../../_images/d60e84d8865b.webp)

Выбираем тип файловой системы **ZFS**, нажав **Enter**

![](../../_images/4f37e1a81192.webp)

Выбираем **stripe**, нажав **Enter**

![](../../_images/354a61c87136.webp)

Жмем на **Space** чтобы выбрать единственный подключенный диск, после чего жмем **Enter**

![](../../_images/a3f66d7c88e5.webp)

Соглашаемся и нажимаем **Enter**

![](../../_images/060178e14384.webp)

Дальше будет происходить клонирование образа системы на диск, ждем полного переноса

![](../../_images/a7231475adb4.webp)

После загрузки выбираем **Complete Install** и нажимаем **Enter**

![](../../_images/f4bb67e2fbf6.webp)

Выбираем перезагрузку системы и нажимаем **Enter**

![](../../_images/7facbe3b73da.webp)

## 3) Настройка интерфейсов

После перезагрузки входим в систему с учетными данными:

login - **root** password - **opnsense**

![](../../_images/b5e4d6763608.webp)

Выберем **Assign Interfaces** под цифрой 1 для настройки интерфейсов

![](../../_images/69ddd8d225c6.webp)

Сетевые интерфейсы идут в том же порядке, что и адаптеры в VirtualBox, поэтому присваиваем интерфейсу **em0** - **WAN**. Оставшимся интерфейсам присваиваем **LAN**

![](../../_images/28baed147221.webp)

Применяем установки, нажимая **y** и **Enter**

![](../../_images/a0056d77bda7.webp)

Для подключения к веб-интерфейсу нужно отключить политики брандмауэра, для этого заходим в shell и пишем в терминале `pfctl -d`

![](../../_images/fa6742a9b297.webp)

## 4) Работа с веб-интерфейсом

Зайдем в браузер с основной операционной системы и перейдем по полученному ip для WAN из раздела выше. В нашем случае это **192.168.0.173**.

![](../../_images/a58a3d330c25.webp)

Зайдем в аккаунт под пользователем **root** и паролем **opnsense**

![](../../_images/1c7082913215.webp)

Далее нас встречает базовая настройка конфигурации системы, выбираем **Next**

![](../../_images/70dd5542838d.webp)

Оставляем настройки по умолчанию и нажимаем **Next**

![](../../_images/ad7620395848.webp)

Оставим базовые настройки для WAN, в случае необходимости, их можно заменить позже

![](../../_images/acaac6f10238.webp)

Зададим нашему LAN **IP Address** - **192.168.1.1/24**

![](../../_images/27471dfae6bf.webp)

В **Deployment type** примем базовую конфигурацию и продолжим, нажав **next**.

![](../../_images/078ee538f882.webp)

В данном разделе надо принять настройки нажатием **Apply**. После этого конфигурация брандмауэра перезагрузится и надо будет снова его отключить

![](../../_images/a9e540b4c903.webp)

## 5) Работа с интерфейсами

В начальной конфигурации наш третий интерфейс никак не настроен. Перейдем во вкладку **interfaces** и выбираем OPT1. В параметре **Description** задаем LAN2, чтобы наш интерфейс так назывался в системе. Задаем статический **IPv4** в параметре **IPv4 Configuration Type** и внизу раздела назначаем **IPv4 address** - 192.168.2.1/24, сохраняем конфигурацию

![](../../_images/59e5bdcac2b7.webp)

Затем в правом верхнем углу на странице должно появится уведомление, где надо нажать **Apply changes**, чтобы настройки применились

![](../../_images/9476f1c5c386.webp)

Проверяем конфигурацию в терминале и видим, что нашему интерфейсу был задан желаемый IP

![](../../_images/bbf84a60f14f.webp)

## 6) Настройка DHCP

Перейдем во вкладку **Services** -> **Dnsmasq DNS&DHCP** -> **General**, проверим все ли интерфейсы заданы в строке Interface. Если нет, то добавляем и применяем настройки.

![](../../_images/bbd061011b28.webp)

Затем перейдем во вкладку **DHCP ranges**, нажмем на плюс и добавим нашему интерфейсу параметры раздачи IP

![](../../_images/3779660d7a78.webp)

Затем перейдем к Firewall -> Rules -> LAN2 и нажмем добавить правила (значок плюса). Проверим, чтобы параметры имели следующие значения

- **Action: Pass**
- **Direction: in**
- **Protocol: any**
- **Source: any**
- **Destination: any** Далее внизу нажимаем **save** и сверху **apply**. Теперь все устройства подключенные в LAN видят друг друга

![](../../_images/1cbb7a971431.webp)

## 7) Настройка правил детектирования

Переходим во вкладку **Services -> Intrusion Detection -> Administration**, во вкладке **settings** ставим настройки как на изображение ниже. При необходимости следует менять интерфейсы, которые будут рассматриваться IDS.

![](../../_images/c1a988a8b83a.webp)

Переходим во вкладку **Download** - в ней находится база данных правил для **suricata**, которые мы будем использовать по ходу курса. Для установки файлов необходимо рядом с названием нажать галочку, после выбора нужных правил нажать **Enable selected**, затем снизу нажать **Download & Update Rules**

![](../../_images/a6726e252742.webp)

Переходим во вкладку **Services -> Intrusion Detection -> Policy** чтобы добавить правила в активные, нажмем на редактирование (иконка карандаша)

![](../../_images/b8e83720a2a8.webp)

В разделе **Rulesets** добавим правила к действующим проставив галочки и нажмем **save**, а затем **apply**

![](../../_images/dd45a1e90999.webp)
