# Настройка маршрутизатора MikroTik

> [!info] Путь в курсе
> Глава 2: Сети и сетевая безопасность / Часть 2. Методы конфигурации сети
>
> **Кейсы:** [2.06 DNS](../../cases/network/2.06%20DNS.md), [2.07 VLAN](../../cases/network/2.07%20VLAN.md), [2.08 NAT](../../cases/network/2.08%20NAT.md)

## 1) Создание виртуальной машины с MikroTik

Для выполнения следующих практических заданий потребуется развернуть и базово настроить маршрутизатор [**MikroTik**](https://mikrotik.com/), а точнее автономную операционную систему [**RouterOS**](https://mikrotik.com/software). Для работы мы будем использовать формат [**CHR (Cloud Hosted Router)**](https://mikrotik.com/software#:~:text=and%20boot%20it.-,CLOUD,-VIRTUAL%20ENVIRONMENTS%20NOW). Скачаем готовый OVA-образ виртуальной машины с официального сайта по [**данной ссылке**](https://download.mikrotik.com/routeros/7.21.4/chr-7.21.4.ova) или с [**облачного хранилища Positive Technologies**](https://storage.ptsecurity.com/seafhttp/f/d49935936faa4e4994e1/?op=view)

После того, как мы скачали OVA-образ, нам необходимо его открыть с помощью VirtualBox, для этого откроем его в проводнике. Затем у вас автоматически откроется окно VirtualBox с настройкой импортирования устройства. VirtualBox сам укажет путь до OVA-образа, поэтому сразу открываем раздел **Settings**.

![](../../_images/1417a656e3a6.webp)

В меню настройки нам необходимо изменить значения следующих параметров:

1. **Name** - MikroTik
2. **Guest OS Type** - Other Linux (64-bit)
3. **RAM** - 512 MB
4. **MAC Address Policy** - Generate new MAC addresses for all network adapters

Итоговая конфигурация в этом меню представлена на изображении далее.

![](../../_images/06720064727c.webp)

После сохранения настройки, выберем виртуальную машину **MikroTik** в левом меню, нажмем на кнопку **Settings**, чтобы перейти в расширенные настройки.

![](../../_images/c8045d28ccf3.webp)

В меню настройки откроем раздел **Display**. В нем необходимо изменить конфигурацию следующим образом:

1. **Video Memory** - 12 MB
2. **Graphics Controller** - VMSVGA

![](../../_images/ea0a99a31ff4.webp)

Перейдем в раздел **Network**.

![](../../_images/6ab7d76ca8ce.webp)

Сейчас мы можем увидеть стандартную конфигурацию сетевого адаптера, которая автоматически выбирает тип адаптера **Bridged Adapter**. В дальнейших кейсах мы будем использовать в основном другой тип адаптера -**Internal Network**, выберем его, чтобы поля стали как на изображении дальше.

![](../../_images/92d81eeb31b5.webp)

Обязательно проверяем чтобы были включены чекбоксы **Enable Network Adapter** и **Virtual Cable Connected**, а затем нажимаем кнопку **OK**, чтобы сохранить изменения. Теперь запустим машину и первый раз авторизируемся в терминале MikroTik. Чтобы запустить машину, необходимо нажать на кнопку **Start** в верхнем меню или же дважды кликнуть по ней в левом меню.

![](../../_images/454cba03d250.webp)

## 2) Настройка MikroTik

После того как маршрутизатор запустится, на экране будет форма авторизации. В MikroTik данные для первого входа в систему выглядят так:

1. **Login** - admin
2. **Password** - пустой

![](../../_images/01cb0a8aae99.webp)

После успешного входа система предложит ознакомится с лицензией на ПО, чтобы пропустить этот пункт введем символ **n**.

![](../../_images/6d1495402885.webp)

Затем нам необходимо сменить пароль, изменим его на **pt-3dt3chl@b**, после чего мы попадем в основной терминал маршрутизатора.

> Пароль **pt-3dt3chl@b** далее будем стандартным для **admin-пользователей**.

![](../../_images/a6fe82da459c.webp)

Виртуальная машина готова к работе. При необходимости можно сделать снимок состояния виртуальной машины или клонировать виртуальную машину.

## 3) Добавление сетевого адаптера

Ранее мы рассматривали сетевую настройку **MikroTik** с использованием только одного сетевого адаптера, но в процессе решения заданий нам понадобится добавлять дополнительные сетевые интерфейсы. Запустим виртуальную машину MikroTik и выполним команду **interface print**

![](../../_images/a419b93946c4.webp)

Если ранее мы еще не добавляли никаких дополнительных интерфейсов, то вывод команды покажет только один интерфейс **ether1**. Предположим, что в ходе настройки нам необходимо использовать 2 интерфейса, тогда чтобы добавить интерфейс, необходимо добавить сетевой адаптер в самом **VirtualBox**. Выключим машину и перейдем в настройки **MikroTik**, а затем откроем раздел **Network**

![](../../_images/20b3f250d269.webp)

Первоначально, можем увидеть настройки сетевого адаптера **Adapter 1**, отвечающего за интерфейс **ether1**. Для непосредственного добавления, перейдем во вкладку **Adapter 2**

![](../../_images/1e327105d45f.webp)

Изначально он будет отключен, а параметры недоступны для заполнения. Активируем чекбокс **Enable Network Adapter**

![](../../_images/547c8752e8e9.webp)

Можем увидеть, что поля параметров стали активны, а также автоматически включился чекбокс Virtual Cable Connected, значит сетевой интерфейс уже активен, но для его работы, нужно произвести настройку. Например нам нужен второй адаптер типа Internal Network, выполним настройку аналогично тому, как настраивали при создании виртуальной машины

![](../../_images/6fc453b0d030.webp)

Обязательно указываем другое имя адаптера, например **intnet2**, чтобы не создать ошибок корреляции, с ранее созданным **intnet**. Далее сохраняем настройки и запускаем MikroTik, чтобы проверить вывод команды **interface print**

![](../../_images/657dcfccc146.webp)

Можем увидеть, что добавился новый интерфейс **ether2**

## 4) Импорт маршрутизатора

В процессе решения заданий вам будут предоставлены готовые **OVA-образы**, заранее сконфигурированные **Positive Technologies**. Для того, чтобы импортировать готовый образ необходимо открыть проводник и открыть скачанный образ. Выберем в качестве **демонстрации **образ **mikrotik_2.ova**

![](../../_images/22e22f81a33b.webp)

Далее откроется диалоговое окно **VirtualBox**, где изначально мы можем увидеть локацию выбранного образа в локальной файловой системе

![](../../_images/4cd8d465da82.webp)

Для корректного импорта сетевых адаптеров необходимо открыть раздел **Settings** и в параметре **MAC Address Policy** выбрать значение **Include all network adapter MAC addresses**

![](../../_images/d24dbba3b1c7.webp)

Затем сохраняем настройку с помощью кнопки **Finish**,** **и можем работать с импортированным образом

![](../../_images/5680d0643301.webp)
