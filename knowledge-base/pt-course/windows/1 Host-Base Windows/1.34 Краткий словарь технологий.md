# Краткий словарь технологий

> [!info] Путь в курсе
> Глава 3: Windows-системы и их безопасность / Часть 1: Host-Base Windows / Эволюция Windows NT

| Сокращение | Расшифровка | Суть |
|---|---|---|
| NT | New Technology | Архитектурная линия современных Windows |
| HAL | Hardware Abstraction Layer | Абстракция железа для ядра |
| WDM | Windows Driver Model | Базовая модель драйверов Windows 2000+ |
| WDF | Windows Driver Frameworks | Фреймворки для драйверов поверх WDM |
| KMDF | Kernel-Mode Driver Framework | WDF для kernel-mode драйверов |
| UMDF | User-Mode Driver Framework | WDF для user-mode драйверов |
| WDDM | Windows Display Driver Model | Современный графический драйверный стек Vista+ |
| XDDM | Windows 2000 Display Driver Model | Старый графический драйверный стек |
| DEP | Data Execution Prevention | Запрет исполнения кода из data pages |
| NX/XD | No-eXecute / Execute Disable | Аппаратный бит запрета исполнения |
| ASLR | Address Space Layout Randomization | Рандомизация адресов памяти |
| KASLR | Kernel ASLR | ASLR для kernel address space |
| UAC | User Account Control | Контроль повышения привилегий |
| MIC | Mandatory Integrity Control | Уровни целостности процессов/объектов |
| UIPI | User Interface Privilege Isolation | Запрет UI-сообщений снизу вверх по integrity level |
| TPM | Trusted Platform Module | Аппаратный модуль доверия и хранения ключей |
| UEFI | Unified Extensible Firmware Interface | Современная firmware-платформа вместо BIOS |
| ELAM | Early Launch Anti-Malware | Ранний запуск antimalware-драйвера |
| VBS | Virtualization-Based Security | Изоляция security-компонентов через гипервизор |
| VTL | Virtual Trust Level | Уровни доверия внутри VBS |
| HVCI | Hypervisor-Protected Code Integrity | Защита проверки kernel code integrity гипервизором |
| WDAC | Windows Defender Application Control | Политики запуска доверенного кода |
| CFG | Control Flow Guard | Защита indirect calls от hijacking |
| WSL | Windows Subsystem for Linux | Linux-среда в Windows |
| VHDX | Virtual Hard Disk v2 | Современный формат виртуального диска Hyper-V |
| ReFS | Resilient File System | Файловая система для отказоустойчивых storage-сценариев |
| SR-IOV | Single Root I/O Virtualization | Прямое предоставление I/O-возможностей VM |
| NUMA | Non-Uniform Memory Access | Архитектура, где память ближе к одним CPU, чем к другим |
| ACPI | Advanced Configuration and Power Interface | Интерфейс управления питанием и конфигурацией железа на уровне ОС |
| AD DS | Active Directory Domain Services | Служба каталогов Microsoft; централизованная аутентификация и авторизация в домене |
| EFS | Encrypting File System | Шифрование отдельных файлов и папок на уровне NTFS |
| NTFS | New Technology File System | Основная файловая система Windows NT |
| PnP | Plug and Play | Автоматическое обнаружение и конфигурирование устройств |
| IRP | I/O Request Packet | Структура ядра для передачи запросов ввода-вывода между драйверами |
| BSOD | Blue Screen of Death | Критический сбой ядра с остановкой системы |
| SSDT | System Service Descriptor Table | Таблица адресов обработчиков системных вызовов в ядре |
| IDT | Interrupt Descriptor Table | Таблица обработчиков прерываний и исключений процессора |
| ROP | Return-Oriented Programming | Техника эксплуатации: цепочки из фрагментов легитимного кода в обход DEP |
| DSE | Driver Signature Enforcement | Обязательная проверка цифровой подписи драйверов на x64 |
| BYOVD | Bring Your Own Vulnerable Driver | Загрузка уязвимого подписанного драйвера для выполнения кода в ядре |
| DACL | Discretionary Access Control List | Список контроля доступа к объекту на усмотрение владельца |
| LSASS | Local Security Authority Subsystem Service | Процесс Windows, хранящий учётные данные и токены активных сессий |
| NTLM | NT LAN Manager | Протокол аутентификации Windows; уязвим к pass-the-hash и relay-атакам |
| PCR | Platform Configuration Register | Регистры TPM, хранящие измерения цепочки загрузки |
| MDM | Mobile Device Management | Централизованное управление и аттестация устройств |
| DWM | Desktop Window Manager | Служба графического композитора Windows |
| WinRM | Windows Remote Management | Служба удалённого управления Windows через WS-Management |
| SMB | Server Message Block | Сетевой протокол доступа к файлам и принтерам Windows |
| DMA | Direct Memory Access | Прямой доступ устройств к оперативной памяти в обход CPU |
| UMS | User-Mode Scheduling | Механизм планирования задач в пространстве пользователя поверх kernel threads |
| AppContainer | — | Sandbox-модель изоляции UWP-приложений с capability-based доступом |
| PatchGuard | Kernel Patch Protection | Механизм защиты целостности ядра на x64; при модификации — BSOD 0x109 |
| Credential Guard | — | Защита учётных данных LSASS через изоляцию в VTL1 (VBS) |
| Shielded VMs | — | Виртуальные машины, защищённые от администратора платформы через BitLocker и vTPM |
| Windows Sandbox | — | Одноразовая изолированная Windows-среда на базе Hyper-V |
| Secured-core | — | Сертификация платформы с обязательно включёнными TPM, Secure Boot, VBS и HVCI |
| VBS Enclaves | — | Программные изолированные области памяти внутри приложения, защищённые гипервизором |
| GPU Partitioning | — | Раздел GPU между VM с поддержкой live migration (Hyper-V, Server 2025) |
| Workplace Join | — | Регистрация устройства в корпоративной инфраструктуре без вступления в домен AD |
| Hyper-V Replica | — | Асинхронная репликация VM на резервный Hyper-V-хост |
| Storage Spaces | — | Программный RAID Windows: отказоустойчивые пулы из обычных дисков без аппаратного контроллера |
