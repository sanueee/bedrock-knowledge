# 6. Windows 8.1 / Server 2012 R2: NT 6.3

> [!info] Путь в курсе
> Глава 3: Windows-системы и их безопасность / Часть 1: Host-Base Windows / Эволюция Windows NT

Итерационный релиз - доработка платформы, заложенной в 8/2012.

**Generation 2 VMs** Первое поколение **Hyper-V** несло в себе большой груз **legacy**: эмулировало старое железо - **BIOS**, **ISA**-шину, **PS/2**-клавиатуру - ради максимальной совместимости. **VM** второго поколения убрали этот слой: только **UEFI**, только **Secure Boot** внутри самой **VM**, только синтетические устройства. Меньше эмулируемого кода - меньше поверхность атаки через уязвимости в эмуляторах устройств. Плюс **Secure Boot** теперь работает не только на хосте, но и внутри гостевой ОС, защищая цепочку загрузки **VM** независимо от хоста.

**Улучшения Hyper-V storage/network** Быстрее **live migration**, лучше динамическая память, **virtual RSS**, расширенные сценарии **SMB 3.0** и **Scale-Out File Server**. Для безопасности инфраструктуры: **SMB 3.0** с шифрованием позволяет передавать данные **VM** по сети без риска перехвата - актуально для **live migration** и общих хранилищ.

**Workplace Join и MDM** До этого момента устройство либо было полноценным членом домена AD, либо не имело никакой корпоративной идентичности - третьего не было. Workplace Join добавил промежуточное состояние: личный ноутбук или планшет сотрудника может зарегистрироваться в корпоративной инфраструктуре, получить **device identity** и условный доступ к ресурсам без вступления в домен. Это фундамент концепции **conditional access**: доступ предоставляется не по факту нахождения в корпоративной сети, а по состоянию и идентичности устройства. Отсюда выросла современная модель **нулевого доверия** к устройствам.
