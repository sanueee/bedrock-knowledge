## Задание

Написать программу `procnet` на C.

**Что делает:**
Читает `/proc/net/tcp`, парсит hex-адреса и порты, выводит список активных TCP-соединений в читаемом виде.

**Формат вывода:**
```
local           remote          state
127.0.0.1:8080  0.0.0.0:0       LISTEN
127.0.0.1:52341 93.184.216.34:443  ESTABLISHED
```

**Детали реализации:**
1. Открыть `/proc/net/tcp` через `fopen()`
2. Пропустить первую строку (заголовок) через `fgets()`
3. Читать строки в цикле через `fgets()`
4. Из каждой строки распарсить:
   - local address: поле 2 (`XXXXXXXX:PPPP` — hex IP:hex port)
   - remote address: поле 3
   - state: поле 4 (hex: `01` = ESTABLISHED, `0A` = LISTEN)
5. Конвертировать hex IP в dotted decimal (`strtol` + побайтовый разбор)
6. Конвертировать hex port в десятичный
7. Вывести только ESTABLISHED и LISTEN

**Функции для использования:**
- `fopen()`, `fgets()`, `fclose()` — чтение файла
- `sscanf()` — парсинг строки по формату
- `strtol(str, NULL, 16)` — hex строка → число
- побитовые операции для разбора IP: `(ip >> 24) & 0xFF` и т.д.

**Где сохранить:** `linux/proc/procnet.c`

**Как проверить:**
```bash
gcc procnet.c -o procnet && ./procnet
```
Сравнить с выводом `ss -tn` или `netstat -tn`.

---

## Моё решение

`fopen` → `fgets` в цикле → `sscanf` для парсинга трёх полей → отдельные функции `print_converted_address` и `print_converted_state` для конвертации. IP разбирается побайтово через сдвиги и маску `0xFF`, порт берётся напрямую из hex. Выравнивание через `snprintf` + `%-25s`.

## Ключевые функции

- `sscanf(line, "%*s %15s %15s %15s", ...)` — пропустить первое поле, взять три следующих
- `sscanf(address, "%X:%X", &ip, &port)` — распарсить hex IP и порт
- `(ip >> N) & 0xFF` — вытащить N-й байт из числа
- `snprintf` + `fprintf(stdout, "%-25s", buf)` — выравнивание колонок
- `strcmp` для сопоставления hex-кода состояния

## Что узнал

- `/proc/net/tcp` — живой снимок ядра, меняется между запусками
- IP в файле хранится в little-endian: байты нужно разворачивать
- `%X` в sscanf читает hex без префикса `0x`
- `& 0xFF` — маска для извлечения младших 8 бит
- `%*s` — прочитать и выбросить поле без сохранения в переменную

## Ошибки и трудности

- Битовые операции для разбора IP — не очевидно самостоятельно, потребовалось объяснение
- `%*d` вместо `%*s` для пропуска первого поля — `%*d` останавливался перед `:`
- `sizeof(buf)` вместо `strlen(buf)` в `write()` — отправлял мусор (из task-06)

## Что бы сделал иначе

Сразу использовать `snprintf` + выравнивание, а не печатать напрямую из функции.
