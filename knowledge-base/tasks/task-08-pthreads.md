# Task 08 — pthreads

## Задание

Написать утилиту `procthreads` на C.

**Что делает:**
- Читает список всех PID из `/proc` (как в task-01)
- Запускает N потоков (например, 4), каждый из которых обрабатывает свою часть PID
- Каждый поток читает `/proc/<pid>/status` и достаёт поля `Name` и `VmRSS` (RSS-память в кБ)
- Все потоки пишут результат в общий массив структур
- После `pthread_join` — вывести список: `PID | Name | VmRSS (kB)`, отсортированный по VmRSS убыванию

**Функции обязательно:**
- `pthread_create()` — запуск потока
- `pthread_join()` — ожидание завершения
- `pthread_mutex_t` + `pthread_mutex_lock/unlock` — защита общего массива при записи

**Где сохранить:** `linux/proc/procthreads.c`

**Компиляция:** `gcc procthreads.c -o procthreads -lpthread`
