# Contains Duplicate

- **Раздел:** 1. Arrays & Hashing
- **Сложность:** Easy
- **Теги:** #hashset
- **Дата:** 2026-07-11
- **Далось:** легко

## Идея (паттерн)

Веду `set` виденных элементов. На каждом шаге проверяю `el in elements` за O(1) — если уже
встречался, дубликат найден. Иначе добавляю. Один проход, early-exit на первом повторе.

## Ловушка / что не сразу увидел

`enumerate` тут избыточен — индекс не нужен, достаточно `for el in nums`. Работает, но лишний слот.
Однострочник `len(set(nums)) != len(nums)` короче, но строит весь set без early-exit — цикл
эффективнее в среднем.

## Сложность

- Время: O(n) — один проход, `in`/`add` по set в среднем O(1).
- Память: O(n) — в худшем случае (нет дублей) в set попадут все элементы.
