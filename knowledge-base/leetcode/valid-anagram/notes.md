# Valid Anagram

- **Раздел:** 1. Arrays & Hashing
- **Сложность:** Easy
- **Теги:** #hashmap #counting
- **Дата:** 2026-07-11
- **Далось:** легко

## Идея (паттерн)

Частоты символов совпадают — значит анаграмма. `Counter(s) == Counter(t)` строит два словаря
`символ → количество` и сравнивает их: одинаковый мультимножественный состав ⇔ анаграмма.
Порядок символов не важен, важен только счёт каждого.

## Ловушка / что не сразу увидел

«Свёрнуто в `Counter`» интервьюер может не засчитать → уметь вручную: один `defaultdict(int)`,
`+1` по `s`, `-1` по `t`, в конце все нули. Для чистой латиницы — массив на 26 int, это настоящая
O(1) память (у `Counter` память O(k) по уникальным символам).

## Сложность

- Время: O(n + m) — построение двух счётчиков за один проход каждый.
- Память: O(k) — k уникальных символов (для латиницы ≤ 26 → условно O(1)).
