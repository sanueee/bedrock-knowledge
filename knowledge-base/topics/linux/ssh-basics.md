# SSH — удалённый доступ к серверу

## Суть (своими словами)

SSH (Secure Shell) — протокол который даёт тебе терминал на удалённой машине через сеть. Ты печатаешь команду на macOS — она выполняется на Ubuntu. Всё зашифровано.

Выглядит как магия, работает просто: клиент (macOS) подключается к серверу (Ubuntu), проходит аутентификацию, дальше всё что ты вводишь — пересылается на сервер и выполняется там.

## Как подключиться

```bash
ssh username@ip-адрес
# пример:
ssh sanueee@192.168.91.138
```

При первом подключении — спросит подтвердить fingerprint (отпечаток ключа сервера). Пишешь `yes`. Это защита от подмены сервера.

## Что нужно на сервере

```bash
sudo apt install openssh-server
sudo systemctl enable ssh   # запускать при старте
sudo systemctl start ssh    # запустить сейчас
```

## Как скопировать файл на сервер (scp)

`scp` — это cp через SSH.

```bash
# с macOS на Ubuntu:
scp /путь/к/файлу.c sanueee@192.168.91.138:~/куда/положить/

# с Ubuntu на macOS:
scp sanueee@192.168.91.138:~/fn2s/linux/fdlist.c ./
```

## Узнать IP сервера

```bash
ip a
# ищи строку inet под реальным интерфейсом (enp2s0, eth0 и т.п.)
# не 127.0.0.1 — это loopback, он только внутри машины
```

## Как это связано с fd

SSH-сессия — это тоже набор fd на сервере. Когда ты подключён, sshd (SSH-демон) держит открытыми сокеты для каждого клиента. Можно проверить:

```bash
sudo ./fdlist $(pgrep sshd | head -1)
```
