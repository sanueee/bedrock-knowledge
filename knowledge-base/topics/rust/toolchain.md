# Rust toolchain

Три инструмента, поставляющиеся как один пакет через `rustup`:

- **`rustup`** — менеджер toolchain'ов. Ставит/обновляет компилятор, переключает между stable/beta/nightly, ставит таргеты для кросс-компиляции. Аналога в C-мире нет — там обычно один системный `gcc`.
- **`rustc`** — собственно компилятор. Прямой вызов `rustc file.rs` работает, но на практике не используется — для проектов из >1 файла нужна build system.
- **`cargo`** — build system + package manager + test runner + generator проектов. Совмещает в себе `make` + `apt` + структуру проекта.

## Cargo — что покрывает

| Команда | Что делает | Аналог в C |
|---------|-----------|-----------|
| `cargo new <name>` | Создаёт проект со скелетом (`Cargo.toml`, `src/main.rs`, `.gitignore`, `git init`) | вручную |
| `cargo build` | Компилирует в `target/debug/` | `make` |
| `cargo build --release` | Оптимизированная сборка в `target/release/` | `make CFLAGS=-O2` |
| `cargo run` | Build + запуск | `make && ./a.out` |
| `cargo test` | Запускает тесты (встроенный фреймворк) | отдельный фреймворк |
| `cargo check` | Только проверка компиляции без линковки (быстро) | нет аналога |
| `cargo add <crate>` | Добавляет зависимость в Cargo.toml | редактируешь Makefile + ставишь -dev пакет |

## Ключевые файлы проекта

- **`Cargo.toml`** — манифест, редактируется руками. Поля: `[package]` (name, version, edition), `[dependencies]`.
  - `edition` — версия языка (2015/2018/2021/2024). Влияет на синтаксис, но крейты разных edition совместимы. Новые проекты — `2021` или `2024`.
- **`Cargo.lock`** — точные версии всего дерева зависимостей. Для бинарей коммитится в git, для библиотек — нет.
- **`src/main.rs`** — точка входа бинарного крейта. Содержит `fn main()`.
- **`src/lib.rs`** — точка входа библиотечного крейта (нет `main`).
- **`target/`** — артефакты сборки. В `.gitignore`.

## Crate

**Crate** — единица компиляции и распространения. Бывают:
- **Binary crate** — есть `main()`, компилируется в исполняемый файл.
- **Library crate** — нет `main()`, экспортирует API для других крейтов.

Зависимости берутся с **crates.io** (аналог npm/pypi). Прописываются в `[dependencies]`:
```toml
[dependencies]
rand = "0.8"
```
Следующий `cargo build` сам скачает крейт со всеми его зависимостями, скомпилирует, слинкует.

## Почему это важно

В C каждый проект изобретает свой Makefile, зависимости тянутся системным пакетным менеджером (apt/brew), версии плавают, кросс-компиляция — отдельная боль. Cargo даёт **единый стандартный путь** для всех Rust-проектов: любой Rust-проект собирается через `cargo build`, без чтения README.

## Ключевые термины (English)

- **toolchain** — набор компилятора + стандартной библиотеки + утилит для конкретной версии.
- **crate** — единица компиляции/распространения.
- **manifest** — `Cargo.toml`, описание проекта.
- **edition** — версия языка (язык эволюционирует, но старые edition остаются совместимы).
- **registry** — crates.io, дефолтный источник зависимостей.
