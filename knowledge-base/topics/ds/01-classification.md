# Классификация типов и структур данных

## 🎯 Учить наизусть — триада «тип данных»

**Тип данных** — характеристика набора данных, определяющая:
1. **диапазон допустимых значений** (range of values);
2. **допустимые операции** над ними (operations);
3. **способ хранения** в памяти (representation / storage).

Это самый вероятный «впиши ответ». Три части, не две, не четыре.

## Что это

Раздел про **рамку** всего курса: чем тип отличается от структуры данных и как
всё классифицируется. **Тип** — про значения и операции (абстракция). **Структура
данных** — про *способ организации* значений в памяти для эффективного доступа.

## Ключевые термины (English)

- **data type** — диапазон значений + операции + представление.
- **primitive / simple type** — неделимый тип (`int`, `char`, `bool`).
- **composite type** — состоит из нескольких элементов (массив, `struct`).
- **static structure** — размер фиксирован на этапе компиляции (compile-time).
- **dynamic structure** — размер меняется во время выполнения (runtime).
- **recursive structure** — содержит ссылку на саму себя (`struct node *next`).
- **strong / weak typing** — строгая/слабая типизация (C — слабо типизирован).

## Зачем нужны типы (4 пункта)

- **Поведение** — какие операции законны (число + число vs строка + строка).
- **Безопасность** — ловит ошибки несовместимых операций.
- **Экономия памяти** — выбор компактного формата (`short` vs `long`).
- **Читаемость** — назначение переменной видно из типа.

Историческая зацепка: в раннем **Basic** типов не было; в **Pascal** наоборот — *всё*
является типом (массив-тип, файл-тип), понятия «тип» и «структура данных» слиты.

## Как работает — классификация

```
                    Типы и структуры данных
                    /                      \
              Простые                    Составные
            /    |    \                  /         \
   Стандартные Перечис- Диапазон-   Статические   Динамические
              лимые    ные         · массив        /         \
                                   · запись   Нерекурсивные  Рекурсивные
                                   · объедин.  · дин. массив  · лин. списки
                                   · множество · дин. множес. · стек/очередь/дека
                                   · последов.               · дерево/граф/хеш
```

Три оси, которые спрашивают:
1. **Простые vs составные** — неделимый vs из нескольких элементов.
2. **Статические vs динамические** — размер на этапе компиляции vs в runtime.
3. **Рекурсивные vs нерекурсивные** — есть ли в определении узла указатель на такой
   же узел. **Признак рекурсивной структуры: `struct node { ...; struct node *next; }`**.
   Список/дерево/граф — рекурсивны; динамический массив — нет.

## Пример

```c
// нерекурсивная динамическая: блок в куче, элементы не ссылаются друг на друга
int *arr = malloc(n * sizeof(int));

// рекурсивная динамическая: узел ссылается на такой же узел
struct node {
    int data;
    struct node *next;   // ← self-reference = рекурсивность
};
```

## Подводные камни

- Путать «тип» и «структуру данных»: тип — значения+операции, структура — организация
  в памяти. В Pascal они слиты, в C — нет.
- Думать, что «динамическое» = «рекурсивное». Динамический массив динамичен, но
  **не рекурсивен** (нет self-reference).
- Забыть третий пункт триады (способ хранения) — частая потеря балла.
