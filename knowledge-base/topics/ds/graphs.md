# Графы (graphs)

> У тебя по теме было пусто — конспект по общим источникам. По калибровке прошлого теста:
> графы включают **A\*** (допустимая эвристика; A\* без эвристики = Дейкстра).

## 1. Определение

**Граф** G = (V, E) — множество **вершин (vertices)** V и **рёбер (edges)** E ⊆ V×V,
связывающих пары вершин. Виды:
- **неориентированный / ориентированный** (undirected / directed) — рёбра без/с направлением;
- **взвешенный / невзвешенный** (weighted / unweighted) — есть/нет вес на ребре;
- **связный, цикличный, дерево** (дерево = связный ацикличный граф, |E| = |V|−1).

## 2. Пример — два представления (на C)

### Матрица смежности (adjacency matrix)
```c
int adj[V][V];          // adj[i][j] = 1 (или вес), если есть ребро i→j
```
- Память **O(V²)**; проверка ребра O(1); перебор соседей O(V). Хорошо для **плотных** графов.

### Список смежности (adjacency list)
```c
typedef struct edge { int to; int w; struct edge *next; } Edge;
Edge *adj[V];           // adj[i] = список рёбер из вершины i
```
- Память **O(V + E)**; перебор соседей O(deg); проверка ребра O(deg). Хорошо для **разреженных**
  графов (E ≪ V²) — обычный случай в реальности.

## 3. Особенности
- Выбор представления — **по плотности**: матрица для плотных (E ~ V²), список для разреженных.
- Обходам нужен массив **посещённости (visited)** — иначе зацикливание на циклах графа
  (в отличие от дерева, где циклов нет и visited не нужен).

## 4. Плюсы и недостатки (представлений)
- **Матрица:** +O(1) проверка ребра, простота; −O(V²) память даже для редкого графа.
- **Список:** +O(V+E) память, быстрый перебор соседей; −O(deg) проверка конкретного ребра.

## 5. Где применяется
- **Сети** (твой вектор!): маршрутизация (граф узлов), топология сети, BGP/OSPF.
- **Соцсети, веб-граф** (PageRank), карты/навигация (кратчайший путь), зависимости (сборка,
  пакеты), планировщики задач (топосорт), компиляторы (граф потока управления CFG).
- **Безопасность:** граф вызовов (call graph) в анализе кода, граф достижимости привилегий.

## 6. Операции (алгоритмы)

### Обход в ширину — BFS (breadth-first search)
**Очередь (FIFO)**. Обходит по уровням от старта. Даёт **кратчайший путь в невзвешенном**
графе (по числу рёбер).
```
visited[start]=1; queue.push(start)
while queue: u=queue.pop(); for v in соседи(u): if !visited[v]: visited[v]=1; queue.push(v)
```
Сложность **O(V + E)** (список смежности).

### Обход в глубину — DFS (depth-first search)
**Стек / рекурсия**. Уходит «вглубь» до упора, потом откат. Применения: поиск циклов,
**топологическая сортировка**, компоненты связности, мосты/точки сочленения.
Сложность **O(V + E)**.

### Дейкстра (Dijkstra) — кратчайший путь во взвешенном графе
**Только неотрицательные веса.** Жадно: на каждом шаге берём непосещённую вершину с
минимальной текущей дистанцией (через **приоритетную очередь / кучу**, см. [[sorting-search]]),
релаксируем её рёбра (`if dist[u]+w < dist[v]: dist[v]=dist[u]+w`).
Сложность **O((V + E)·log V)** с двоичной кучей.
> Почему не работает с отрицательными рёбрами: жадность «зафиксировал минимум — больше не
> трогаю» ломается, если позже найдётся отрицательное ребро, удешевляющее путь. Для
> отрицательных — Беллман–Форд O(V·E).

### A* (A-star) — Дейкстра + эвристика
Приоритет вершины = `g(v) + h(v)`, где g — реальная стоимость от старта, h — **эвристика**
(оценка остатка до цели). Ускоряет поиск к **конкретной** цели, «целясь» в неё.
- **Допустимая эвристика (admissible):** h **никогда не переоценивает** реальный остаток
  (h(v) ≤ истинное расстояние). Гарантирует оптимальность пути.
- **A\* с h ≡ 0 = Дейкстра** (без подсказки — обычный равномерный поиск). ← частый вопрос.

### MST — минимальное остовное дерево (упоминание)
Прим (Prim) / Краскал (Kruskal) — связать все вершины минимальным суммарным весом рёбер.
Краскал использует **систему непересекающихся множеств (union-find)**.

## 7. Сложность (сводка)

```
Алгоритм   | Сложность           | Условие
-----------|---------------------|---------------------------
BFS        | O(V + E)            | невзвеш. кратчайший путь
DFS        | O(V + E)            | обход, циклы, топосорт
Дейкстра   | O((V+E)·log V)      | веса ≥ 0
Беллман–Форд| O(V·E)             | допускает отрицательные веса
A*         | ≤ Дейкстра (зависит от h) | нужна допустимая эвристика
```
Память: матрица O(V²), список O(V+E); обходы — O(V) под visited + очередь/стек.

## Сквозные темы
- **Структуры внутри алгоритмов:** BFS → очередь; DFS → стек; Дейкстра/A\* → куча
  (priority queue); Краскал → union-find. Граф — «потребитель» почти всех изученных структур.
- **Память:** список смежности — динамические узлы (dangling/UAF риски, как у списков).

## Параллели и trade-offs
- **Матрица vs список** — плотный vs разреженный (память O(V²) vs O(V+E)).
- **BFS vs DFS** — ширина (кратчайший путь, очередь) vs глубина (топосорт/циклы, стек).
- **Дейкстра vs A\*** — равномерный поиск vs направленный к цели (эвристика).
- **Python:** `networkx`; куча — `heapq`. **Rust:** `petgraph`; куча — `BinaryHeap`.

## Ключевые термины (English)
- **graph / vertex / edge** — граф / вершина / ребро.
- **directed / undirected, weighted / unweighted** — ориентированный/нет, взвешенный/нет.
- **adjacency matrix / adjacency list** — матрица / список смежности.
- **BFS / DFS** — обход в ширину / в глубину.
- **shortest path** — кратчайший путь.
- **Dijkstra, Bellman–Ford, A\*** — алгоритмы кратчайшего пути.
- **admissible heuristic** — допустимая эвристика (не переоценивает).
- **MST (minimum spanning tree)** — минимальное остовное дерево.
- **topological sort** — топологическая сортировка.
- **union-find / disjoint set** — система непересекающихся множеств.
