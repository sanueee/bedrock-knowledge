# Простые типы данных

## 🎯 Самый вероятный вопрос (по оценке пользователя) — почему в C нет диапазонных типов

**Вопрос:** почему диапазонных типов (subrange, как `0..120` в Pascal) нет в C?

**Ответ:** C по дизайну **не встраивает проверку границ в рантайме** и доверяет
программисту (философия *«доверяй программисту»*, минимум накладных расходов). Язык
не enforce'ит диапазон значений.

**Как сэмулировать в C** (задача из лекции) — чистого языкового способа нет, только руками:
- `typedef` + ручная проверка / `assert(x >= 0 && x <= 120)` в сеттере;
- либо `enum`/макрос с проверочной функцией.

Суть: **нет языковой поддержки → только runtime-проверки вручную**.

## Ключевые термины (English)

- **IEEE 754** — стандарт представления чисел с плавающей точкой.
- **short-circuit evaluation** — ленивое вычисление `&&`/`||`.
- **subrange type** — диапазонный тип (подмножество базового с границами).
- **enumeration / enum** — перечислимый тип (именованные константы).
- **weak typing** — слабая типизация (C).

## Стандартные типы

- **Целые** `short`(~2б)/`int`(~4б)/`long`(~4б)/`long long`(4–8б). **Размер зависит от
  платформы** — стандарт гарантирует только `short ≤ int ≤ long ≤ long long`.
- **Вещественные** `float`(4б)/`double`(8б)/`long double`. Из-за **IEEE 754**:
  `0.1 + 0.2 != 0.3` (приближённое двоичное представление), накопление ошибки округления
  → float нельзя сравнивать через `==`.
- **Логические** `bool`. **Short-circuit**: `&&` не считает правое, если левое ложно;
  `||` — если левое истинно.
- **Символы** `char` (1 байт, ASCII); `wchar_t` (2/4 байта) для Unicode, литерал `L'А'`.

### Безопасный приём с short-circuit (частый вопрос «зачем такой порядок»)

```c
if (i < N && A[i] != x) i++;   // если i >= N, A[i] не вычисляется → нет выхода за границу
```
Порядок операндов в `&&` = защита от чтения за границей массива.

## Перечислимые (`enum`)

- Авто-нумерация **с 0**; явное `= 1` продолжает инкремент.
- Перечислители — **константы**; ограниченный набор → безопаснее «магических чисел».
- Приводятся к `int`; арифметика возможна, но не рекомендуется (теряется смысл).
- C23: базовый тип — `enum : char season { ... };`.

### `enum` vs `#define`

| | `enum` | `#define` |
|---|--------|-----------|
| Что | настоящий тип, scope | текстовая замена препроцессора |
| Тип/проверки | есть | нет |
| Отладчик | видит имя | видит число |
| `switch-case` | дружит | нет типа |

Вывод: `enum` типобезопаснее и читаемее, `#define` — просто текст без типа.

## Подводные камни

- «`int` всегда 4 байта» — нет, зависит от платформы.
- Сравнение float через `==` — баг (IEEE 754).
- Перепутать порядок в `&&` при проверке индекса — выход за границу.
