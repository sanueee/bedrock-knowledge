# Последовательность / Sequence

## Определение

**Упорядоченный** набор элементов одного типа: порядок важен, **дубликаты разрешены**.
Антипод множества (там — ни порядка, ни дубликатов; главная операция membership,
здесь — доступ по позиции/обход).

## Ключевые термины (English)

- **sequence** — последовательность; **ordered** — упорядоченный.
- **contiguous (array-based)** — реализация массивом (подряд в памяти).
- **linked (list-based)** — реализация списком (указатели).
- **cache locality** — кэш-локальность (почему массив на железе быстрее).

## Сравнение множества и последовательности

```
              порядок    дубликаты    главная операция
множество     нет        нет          membership (x in A)
последоват.   ДА         ДА           доступ по позиции / обход
```

## Две реализации и сложность (канон)

```
операция                 массив         связный список
доступ по позиции i      O(1)           O(n)
поиск по значению        O(n)           O(n)
вставка/удал. в начало   O(n) сдвиг     O(1)
вставка/удал. в конец    O(1)*          O(1) с хвост-указателем
вставка/удал. в середину O(n) сдвиг     O(1)**
конкатенация             O(n+m)         O(1) с хвостом

*  амортизированно (динамический массив)
** перецепка O(1), но ПОИСК позиции O(n) — вопрос 24 теста
```

**Перекрёст:** массив быстр в доступе / медлен в перестройке; список — наоборот.
Выбор реализации = что делаешь чаще.

## Где применяется

Строки, буферы I/O, append-only логи, потоки данных. Список выбирают, когда **размер
задачи определяется в конце потока данных** (вопрос 23 теста) — длина неизвестна заранее.

## Параллель (для устного)

Python `list`/`str`, Rust `Vec`/`String` — последовательности на массивах. Современный
поинт: на реальном железе массив почти всегда быстрее списка даже в «списочных»
сценариях — cache locality/prefetching; Big-O не видит константы кэша (док Rust
`LinkedList` сам отговаривает от его использования).

## Подводные камни

- «Вставка в список O(1)» — только при ИЗВЕСТНОЙ позиции; с поиском — O(n).
- Путать последовательность (порядок+дубли) и множество (ни того, ни другого).
