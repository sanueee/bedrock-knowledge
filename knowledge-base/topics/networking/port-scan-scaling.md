# Масштабирование connect-scan: bounded concurrency + окно проб / Bounded concurrency scan

## Что это

Как превратить пробу **одного** порта (B-8) в скан **диапазона** портов, не исчерпав дескрипторы и не потеряв вердикты. Ядро — **окно параллелизма** (bounded concurrency): фиксированное число проб «в полёте» (in-flight probes), которое доливается по мере закрытия готовых. Реализация — `networking/portscan.c` (B-10, первое интеграционное блока B).

## Ключевые термины (English)

- **bounded concurrency** — ограничение числа одновременных проб фиксированным окном; не «открыть 65535 сокетов разом»
- **in-flight probes** — сокеты, по которым `connect` уже отправлен, но вердикт ещё не вынесен
- **window / slot** — массив слотов фиксированного размера (`WINDOW = 256`); слот = одна активная проба, `fd == -1` → свободен
- **file descriptor exhaustion** — `RLIMIT_NOFILE` (обычно 1024), `socket()` при исчерпании → `EMFILE`
- **liveness condition** — условие продолжения главного цикла
- **relative timeout** — `epoll_wait` ждёт интервал в мс **от «сейчас»**, не абсолютный момент
- **monotonic clock** — `CLOCK_MONOTONIC`; дедлайны не ломаются от NTP

## Как работает

Одиночная проба B-8 (non-blocking `connect` → `epoll` ждёт `EPOLLOUT` → `getsockopt(SO_ERROR)` = вердикт) масштабируется четырьмя инженерными добавками:

1. **Окно слотов.** `struct probe slots[WINDOW]` — каждый слот хранит `fd`, `port`, `deadline_ms`. Свободный помечен `fd == -1` (`memset(slots, -1, ...)` при старте — байты `0xFF` дают `-1` для `int`/`long long`). Долив: пока есть свободный слот и остались порты — `start_probe` следующего порта.

2. **fd → port ассоциация.** epoll в событии отдаёт индекс слота через `epoll_event.data.u32 = slot_idx`. Не `port_of_fd[fd]` — тогда переиспользование номера fd ядром после `close` рассинхронизирует таблицу. Индекс слота от этого класса багов защищён структурно.

3. **Один epoll на весь скан.** `epoll_create1(0)` один раз; все сокеты окна регистрируются в него на `EPOLLOUT`. Главный `epoll_wait` разгребает готовые скопом.

4. **Три вердикта на диапазоне.** open — `SO_ERROR == 0`; closed — `SO_ERROR == ECONNREFUSED` (пришёл RST); **filtered — отсутствие события** до дедлайна (фаервол дропает молча). open/closed приходят как события epoll; filtered — это **тишина**, её надо активно вычистить проходом по просроченным слотам.

## Подводные камни

Именно здесь всплыли баги B-10 (4 итерации `/check`):

- **`epoll_wait` таймаут — относительный, не абсолютный.** 4-й аргумент = сколько мс ждать **от сейчас**. Передать `now + timeout` (абсолютный момент) = ждать миллиарды мс ≈ вечность. Правильно: найти **минимальный дедлайн среди активных** слотов, вычесть `now_ms()`, **клампнуть отрицательное в 0** (иначе `epoll_wait` трактует `< 0` как «бесконечно»).

- **Условие выхода главного цикла = порты ИЛИ пробы в полёте.** `while (next_port <= port_to)` выходит, как только все порты **запущены**, — но пробы ещё висят в окне. open/closed на loopback резолвятся мгновенно в тот же `epoll_wait` и баг **прячут**; filtered (вердикт = ожидание дедлайна) требует пережить ещё итерацию — на нём баг и вылезает (`0/0/0/0`). Правильно: `next_port <= port_to || active > 0`.

- **Счётчик in-flight парен занятию слота.** `active++` ровно там, где слот занят (`start_probe` вернул `SUCCESS`); `active--` в **каждой** точке `slots[k].fd = -1` (filtered-проход и разбор событий). Лишний `active--` на пути, где слот **не** занимался (`CONNECT_ERROR`, `EMFILE`), уводит счётчик в минус → преждевременный выход цикла.

- **`EMFILE` — штатная ветка, не фатал.** `socket()` при исчерпании fd → `-1`/`EMFILE`; `start_probe` возвращает «лимит», главный цикл **не** инкрементит `next_port`, ждёт освобождения окна. Потерять порт нельзя.

- **`CLOCK_MONOTONIC`, не `REALTIME`** — дедлайны на реальных часах ломаются при переводе времени.

## Пример

`networking/portscan.c` — главный цикл (суть):

```
while (!stop && (next_port <= port_to || active > 0)) {
    /* долить окно: find_free_slot → start_probe, active++ на SUCCESS */
    /* filtered-проход: slots[k].deadline_ms < now → close, fd=-1, active-- */
    /* epoll_timeout = min_deadline_среди_активных - now; кламп >= 0 */
    /* epoll_wait → на событие: getsockopt(SO_ERROR) → open/closed/error, close, fd=-1, active-- */
}
```
