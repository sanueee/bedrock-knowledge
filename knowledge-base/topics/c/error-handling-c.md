# Обработка ошибок в C

## Суть (своими словами)

В C нет исключений. Ошибки возвращаются через возвращаемое значение функции или через глобальную переменную `errno`. Нужно явно проверять каждый вызов, который может упасть.

Главный принцип из task-01: **внешний мир — всегда обрабатывать, внутренняя логика — можно упростить**.

## Внешний мир vs внутренняя логика

**Внешний мир** — всё что приходит снаружи программы:
- Аргументы командной строки
- Файлы (могут не существовать, нет прав)
- Сеть (соединение может упасть)
- Системные вызовы

**Внутренняя логика** — то что программа контролирует сама. Можно использовать `assert` для проверок инвариантов в дебаге.

## Пример из моего кода

```c
// Парсинг аргумента — внешний мир, проверяем всё
char *endptr;
errno = 0;
uint64_t pid = strtoull(argv[1], &endptr, 10);

if (argv[1] == endptr) {           // нет числа вообще
    fprintf(stderr, "error: int required\n");
    return 1;
}
if (errno == ERANGE) {             // число слишком большое
    fprintf(stderr, "error: int overflow\n");
    return 1;
}

// Открытие файла — внешний мир
FILE* inp = fopen(path, "r");
if (inp == NULL) {
    fprintf(stderr, "error: opening %s\n", path);
    return 1;
}
```

## errno

`errno` — глобальная переменная, устанавливается при ошибке системного вызова.

```c
#include <errno.h>

errno = 0;                    // сброс перед вызовом
int fd = open(path, O_RDONLY);
if (fd == -1) {
    perror("open");           // выводит: "open: No such file or directory"
    // или:
    fprintf(stderr, "open failed: %s\n", strerror(errno));
}
```

Важно: `errno` не сбрасывается автоматически. Нужно проверять сразу после вызова.

## Частые ошибки

**Забыть `\n` в stderr** — сообщение сливается с приглашением терминала:
```
$ ./procinfo
error: argument required$    <- слипается
```

**Не проверить возврат функции** — самая частая причина crash.

**Не сбросить errno перед вызовом** — `errno` может быть ненулевым от предыдущего вызова.

## Коды возврата main

По соглашению:
- `return 0` — успех
- `return 1` (или ненулевое) — ошибка

Оболочка проверяет `$?` — последний код возврата.

## Man pages / docs

- `man 3 errno` — переменная errno
- `man 3 perror` — вывод ошибки по errno
- `man 3 strerror` — строка по errno
