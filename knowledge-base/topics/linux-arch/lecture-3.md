## 1. Синтаксис команды

Любая команда в Linux — это инструкция из трёх частей, которые принято читать как предложение:

```
команда   [ключи]   [аргументы]
 глагол  прилагат.  существит.
```

**Команда (глагол)** — имя программы, которую нужно запустить. Всегда стоит первой. Shell ищет её по каталогам из переменной `PATH`. Если программа не в `PATH` — нужен явный путь: `./myprog` или `/usr/local/bin/myprog`.

**Ключи / опции (прилагательные)** — модифицируют поведение команды:
- **Короткая форма:** один дефис + один символ: `-a`, `-l`, `-h`. Краткие ключи можно объединять: `ls -la` = `ls -l -a`. Некоторые ключи принимают значение: `-n 5`.
- **Длинная форма:** два дефиса + слово: `--all`, `--human-readable`. Значение передаётся через `=`: `--lines=5` или пробел: `--lines 5`.

**Аргументы (существительные)** — объекты, над которыми выполняется действие: имена файлов, каталогов, строки. Обычно стоят в конце.

```bash
ls -lh /var/log          # команда=ls, ключи=-lh, аргумент=/var/log
rm -rf /tmp/old_build    # команда=rm, ключи=-rf, аргумент=/tmp/old_build
```

### man-нотация

Во всей документации (`man`, `--help`) используются типографские соглашения:

| Обозначение | Смысл |
|-------------|-------|
| `[...]` | Необязательный параметр — можно опустить |
| `<...>` | Обязательный параметр — нужно подставить значение |
| `{A\|B\|C}` | Взаимно исключающие варианты — выбрать один |
| `...` | Параметр может повторяться несколько раз |

Пример из `man ls`:
```
ls [OPTION]... [FILE]...
```
Означает: ключи необязательны и могут повторяться; аргументы-файлы тоже необязательны и могут быть несколько.

## 2. Управляющие символы (Control Keys)

Терминал — это не просто место ввода текста. Он обрабатывает особые управляющие символы ещё до того, как строка попадает в программу. Это механизм **дисциплины линии (line discipline)** в ядре.

| Сочетание | Сигнал / действие | Что происходит |
|-----------|-------------------|----------------|
| `Ctrl+C` | **SIGINT** | Штатное прерывание процесса. Большинство программ обрабатывают его и завершаются корректно. |
| `Ctrl+\` | **SIGQUIT** | Аварийное завершение + создание core dump (образа памяти для отладки). |
| `Ctrl+Z` | **SIGTSTP** | Приостановка (suspend) текущего процесса. Процесс переходит в фоновый режим в состоянии T (stopped). Возобновить: `fg` (на передний план) или `bg` (в фоне). |
| `Ctrl+D` | EOF (конец файла) | Завершение ввода — программа получает сигнал конца потока. В пустой строке shell воспринимает это как команду выхода (logout). |
| `Ctrl+L` | — | Очистка экрана терминала. Аналог команды `clear`. Содержимое буфера прокрутки не стирается. |
| `Ctrl+W` | — | Удаление последнего введённого **слова** (до предыдущего пробела). |
| `Ctrl+U` | — | Удаление всей введённой строки от начала до курсора. |
| `Ctrl+A` | — | Перейти в **начало** строки. |
| `Ctrl+E` | — | Перейти в **конец** строки. |
| `Ctrl+R` | — | **Поиск по истории** команд в обратном порядке. Начать вводить часть команды — shell найдёт совпадение. |

**Разница между Ctrl+C и Ctrl+Z:** `Ctrl+C` убивает процесс, `Ctrl+Z` только замораживает его — он остаётся в памяти и может быть продолжен.

## 3. Справочная система

### man — основной источник

`man` (manual) — встроенная документация по командам, системным вызовам и конфигурационным файлам. Организована в **секции**:

| Секция | Содержимое |
|--------|-----------|
| 1 | Пользовательские команды (`ls`, `grep`, `find`) |
| 2 | Системные вызовы (`open`, `read`, `fork`) |
| 3 | Библиотечные функции (`printf`, `malloc`) |
| 4 | Специальные файлы устройств (`/dev/null`, `tty`) |
| 5 | Форматы конфигурационных файлов (`passwd`, `fstab`) |
| 7 | Разное: соглашения, концепции, стандарты |
| 8 | Команды администратора (`mount`, `fdisk`, `iptables`) |

Если имя совпадает в нескольких секциях — указывается номер явно:
```bash
man 2 open     # системный вызов open()
man 3 printf   # библиотечная функция printf()
man 5 passwd   # формат файла /etc/passwd
```

### Поиск в man

```bash
man -k keyword    # поиск по ключевому слову в кратком описании (= apropos)
whatis ls         # одна строка: что делает команда
```

### Навигация внутри man

Man открывает страницу через `less`. Управление:
- `Space` / `b` — вперёд / назад на страницу.
- `/слово` — поиск вперёд; `n` — следующее совпадение.
- `q` — выход.

## 4. Переменные окружения

**Окружение (environment)** — набор переменных вида `ИМЯ=значение`, который наследует каждый запущенный процесс от родителя.

Это оперативный механизм настройки: значение переменной влияет на поведение программы прямо сейчас, без перезапуска системы.

### Ключевые переменные

| Переменная | Назначение |
|------------|-----------|
| `PATH` | Список каталогов (через `:`) для поиска исполняемых файлов. Когда вы вводите `ls`, shell ищет программу в каждом каталоге из `PATH` по очереди. |
| `HOME` | Путь к домашнему каталогу текущего пользователя. Тильда `~` — сокращение для `$HOME`. |
| `USER` | Имя текущего пользователя. |
| `SHELL` | Полный путь к текущему интерпретатору (`/bin/bash`). |
| `PS1` | Строка приглашения командной строки (prompt). Например: `PS1='\u@\h:\w\$ '` — имя пользователя, хост, текущий каталог. |
| `LANG` | Локаль системы: язык сообщений, кодировка, формат дат. Пример: `LANG=ru_RU.UTF-8`. |
| `EDITOR` | Текстовый редактор по умолчанию (используется `git`, `crontab -e` и др.). |
| `TERM` | Тип терминала (например, `xterm-256color`). Влияет на обработку управляющих последовательностей. |

### Работа с переменными

```bash
echo $PATH               # вывести значение переменной
env                      # показать всё окружение
export MY_VAR="hello"    # создать/изменить переменную и экспортировать дочерним процессам
unset MY_VAR             # удалить переменную
MY_VAR=value command     # задать переменную только для одного запуска команды
```

**Важно:** переменная без `export` видна только текущему shell, но не программам, которые он запускает.

### PATH и безопасность

Порядок каталогов в `PATH` имеет значение. Если в начале стоит `.` (текущий каталог), злоумышленник может подложить в него поддельную программу с именем `ls` или `cd`. Поэтому в `PATH` суперпользователя `.` не должно быть никогда.

## 5. Конфигурационные dot-файлы

**Dot-файлы** — скрытые файлы (имя начинается с `.`) в домашнем каталоге. Они определяют долговременные настройки окружения. `ls -a` показывает их.

### Когда читается какой файл

Bash различает два режима запуска:

| Тип сеанса | Какой файл читается |
|------------|---------------------|
| **Login shell** (вход в систему: SSH, Ctrl+Alt+F1) | `~/.bash_profile` или `~/.profile` |
| **Interactive non-login shell** (новая вкладка терминала) | `~/.bashrc` |
| **Non-interactive shell** (скрипт запущен напрямую) | Файл из переменной `BASH_ENV`, если задана |

Типичная практика: в `.bash_profile` написать `source ~/.bashrc`, чтобы настройки были одинаковы при любом входе.

### Назначение основных файлов

**`~/.bashrc`** — настройки интерактивного bash:
- Псевдонимы (`alias ll='ls -lh'`).
- Функции.
- Настройка приглашения (`PS1`).
- Переменные окружения, нужные только в интерактивной работе.

**`~/.bash_profile`** / **`~/.profile`** — настройки сеанса входа:
- Переменные окружения, которые должны быть везде (`PATH`, `EDITOR`, `LANG`).
- Запуск фоновых программ при входе.

**`~/.bash_history`** — история команд. По умолчанию хранит последние 500–2000 команд. Команда `history` показывает список; `!номер` — повторить команду по номеру; `!!` — последнюю команду.

**`~/.bash_logout`** — выполняется при выходе из login shell (очистка временных файлов и т.п.).

**`~/.inputrc`** — настройки readline: раскладка клавиш, поведение Tab, чувствительность к регистру при автодополнении.

### Пример .bashrc

```bash
# Псевдонимы
alias ll='ls -lh --color=auto'
alias ..='cd ..'
alias grep='grep --color=auto'

# Настройка приглашения
PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[0m\]\$ '

# Расширение PATH
export PATH="$HOME/.local/bin:$PATH"

# Редактор по умолчанию
export EDITOR=vim
```

### Перезагрузка настроек без перезапуска

```bash
source ~/.bashrc   # применить изменения в текущем сеансе
# или
. ~/.bashrc        # то же самое, точка = source
```
