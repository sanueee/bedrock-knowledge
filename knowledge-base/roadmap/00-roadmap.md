### Ритм 3:1 (B : C)

Договорённость 2026-06-04, на время совместного прохождения B и C. На каждые 3 задания из B — 1 из C; `give-task` по умолчанию рекомендует B, переключая на C каждое 4-е. Текущее состояние (C=5, B=6) — перекос выправлен. С последней C-задачи (C-5) прошло 3 B-задачи (B-4, B-5, B-6) → **по ритму следующая сессия = C-6**, если пользователь не перебьёт. Но: перед B-7 отмечена рекомендация `/theory` по [[nonblocking-poll]] — её можно вклинить вне ритма. Пользователь может перебить ритм. Детали — `give-task` skill → шаг 4. Снять ритм при закрытии B-26 или конца карты C.
