# ds/ — структуры данных на C

Реализации структур данных и операций над ними под экзамен «Структуры данных»
(временный учебный блок, дедлайн ~2026-06-20).

Здесь живёт **код**: `*.c` с реализациями (динамический массив, список, стек,
очередь, BST, куча, хеш-таблица, граф, сортировки и т.д.).

Теория, конспекты, статус подготовки и журнал пробных экзаменов — в
`knowledge-base/topics/ds/` (хаб: `00-index.md`).

Скилл, который ведёт подготовку: `.claude/skills/exam/skill.md` (триггер `/exam`).

## Конвенция

- Один файл — одна структура или одна группа операций: `dynamic_array.c`, `linked_list.c`, `bst.c`, `sorts.c`, ...
- Сборка: `gcc -Wall -Wextra -g -o <name> <name>.c`
- Если структура переиспользуется в задачах — выносить в `<name>.h` + `<name>.c`.
