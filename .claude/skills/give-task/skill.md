# Скилл: give-task

Используется когда пользователь говорит "у меня есть N часов/минут" или "дай задание".

---

## Алгоритм

1. **Прочитай** `.claude/strategy/learning-strategy.md` — что сейчас текущий этап и следующая тема.

2. **Прочитай** `knowledge-base/00-roadmap.md` — какой последний выполненный task, что в прогрессе.

3. **Определи масштаб** по времени:

   | Время | Тип задачи |
   |-------|------------|
   | < 30 мин | Концептуальная задача или чтение с вопросом. Без написания кода. |
   | 30–60 мин | Задача на одну конкретную функцию или системный вызов. |
   | 1–2 часа | Мини-утилита с полным циклом: написать → собрать → протестировать. |
   | 2+ часов | Новый task с полным циклом: задание → код → ревью → документация в vault. |

4. **Сформулируй задание** — конкретно:
   - Что написать (название, что принимает, что выводит).
   - Какие функции/системные вызовы использовать (по стратегии).
   - На каком Linux-файле/механизме тренироваться.
   - Где сохранить код (`linux/proc/`, `linux/fd/` и т.д.).
   - Что создать в vault (`knowledge-base/tasks/task-NN.md`).

5. **Создай файл задания** `knowledge-base/tasks/task-NN.md` сразу — с заполненным разделом "Задание".
   Остальные разделы оставить пустыми — пользователь заполнит после выполнения.

---

## Чего не делать

- Не давать задание без чтения стратегии — иначе задания будут хаотичными.
- Не придумывать задачи "из головы" — только по стратегии.
- Не давать задание которое уже выполнено (проверить 00-roadmap.md).
- Не давать две темы сразу — одна задача, один навык.
