# bedrock-knowledge

систематическое самообучение системному программированию и безопасности. c, linux, сети, немного rust. код и конспекты к нему.

## структура

```
sections/
  networking/   задания на c — сокеты, dns, http, tls, raw sockets, icmp, сканер портов
  linux/        процессы, fd, pipes, сигналы, потоки, /proc
  ds/           структуры данных и алгоритмы
  rust/         по мере чтения the rust book
  leetcode/     отдельный трек
knowledge-base/
  topics/       конспекты
  roadmap/      текущая позиция и журнал заданий
  strategy/     план блоков
```

## как это устроено

каждое задание проходит один цикл: постановка (`task-*.md`) → код → ревью с разбором ошибок → конспект в `topics/`. в task-файле остаётся разбор: что не получилось с первого раза и почему.
