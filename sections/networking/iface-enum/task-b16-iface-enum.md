# B-16 — Interface enumeration

**Тип:** атомарное (позиция 16/26, Фаза 4 — Raw sockets + L2/L3).
**Синтез опоры:** работа с `struct sockaddr_in`/`inet_ntop` (B-1 tcp-echo, getaddrinfo), парсинг текстового формата вручную (B-12 DNS wire format — но здесь наоборот, готовый текст `/proc`), endianness/`ntohl` (B-12).

Прямо кормит B-20 (ICMP ping sweep — откуда берётся `/24`) и B-25 (host discovery — выбор ARP vs ICMP по сравнению target-сети с локальными интерфейсами).

## Задание

Написать `sections/networking/iface-enum/ifenum.c` — утилиту, которая:
1. перечисляет **сетевые интерфейсы** машины с их IPv4-адресом и маской, маску печатает в CIDR-нотации (`/24`);
2. читает **default gateway** из `/proc/net/route` и привязывает его к нужному интерфейсу.

```
usage: ./ifenum

lo       127.0.0.1        /8     (no gateway)
eth0     192.168.1.42     /24    gw 192.168.1.1
wlan0    10.0.0.7         /24    gw 10.0.0.1
```

(Достаточно **IPv4** (`AF_INET`). IPv6 — опциональный бонус в конце, не обязателен для закрытия задания. Порядок и точный вид колонок — на твоё усмотрение, главное: имя, IP, префикс, gateway.)

### Центральная идея — два независимых источника, которые надо сшить

Данные приходят из **двух разных мест ядра**, и задача — соединить их по имени интерфейса:

- **`getifaddrs()`** — API, отдаёт **связный список** (`struct ifaddrs`) всех адресов на всех интерфейсах. Здесь есть имя (`ifa_name`), сам адрес (`ifa_addr`) и маска (`ifa_netmask`) — но **нет** маршрутов/gateway.
- **`/proc/net/route`** — текстовая таблица маршрутизации ядра. Здесь есть **default route** (строка с `Destination == 00000000`), её `Gateway` и `Iface` — но адреса интерфейса тут нет.

Сшивка идёт по полю `Iface` из `/proc/net/route` ↔ `ifa_name` из `getifaddrs()`. Это и есть суть: сканер собирает целостную картину сети из разрозненных источников ядра.

### Две ловушки, ради которых задание и существует

1. **`ifa_addr` бывает `NULL`, и семейство адреса надо проверять ДО приведения указателя.** Список от `getifaddrs()` содержит записи и для не-IP адресов (`AF_PACKET` — L2/MAC), и записи без адреса вовсе. Слепой каст `(struct sockaddr_in *)ifa_addr` без проверки `ifa_addr != NULL && ifa_addr->sa_family == AF_INET` — это чтение мусора / разыменование NULL. Семейство — первое поле `sockaddr`, оно валидно всегда; читаешь его, и только если `AF_INET` — приводишь к `sockaddr_in`.

2. **`Gateway` в `/proc/net/route` — hex в host-byte-order (little-endian на x86), а не «как читается».** Строка `0100A8C0` — это НЕ `01.00.A8.C0`. Байты лежат в порядке little-endian: `C0 A8 00 01` = `192.168.0.1`. То есть 32-битное значение уже в том порядке, в каком его положил бы `inet_addr` в память. Разберись сам, нужен ли тут `ntohl` или наоборот — это главный endianness-момент задания, не угадывай, проверь на реальном выводе своей машины.

### Алгоритм (пошагово)

**Часть 1 — интерфейсы (`getifaddrs`):**
1. Получить список всех адресов: `getifaddrs(&head)` (проверить возврат `-1` → `perror`).
2. Идти по связному списку от `head` через поле `ifa_next` до `NULL`: обычный `for (p = head; p; p = p->ifa_next)`.
3. Для каждой записи — **отфильтровать**: пропустить если `ifa_addr == NULL` или `ifa_addr->sa_family != AF_INET`. Только тогда безопасно привести `(struct sockaddr_in *)p->ifa_addr`.
4. Достать IP: из `sockaddr_in.sin_addr` в строку — `inet_ntop(AF_INET, &sin->sin_addr, buf, sizeof buf)`.
5. Достать маску: `p->ifa_netmask` привести так же к `sockaddr_in`, взять `sin_addr` → перевести в префикс (popcount битов маски: `__builtin_popcount(ntohl(mask.s_addr))` **или** ручной цикл по битам — разберись, зачем тут `ntohl` и меняет ли он результат popcount).
6. Освободить список: `freeifaddrs(head)` (ровно один раз, после того как всё использовал).

**Часть 2 — default gateway (`/proc/net/route`):**
7. Открыть файл: `fopen("/proc/net/route", "r")` (проверить `NULL`).
8. Пропустить строку-заголовок (первая строка — имена колонок), дальше читать построчно: `fgets()` в цикл.
9. Разобрать поля строки: `sscanf()` по формату `"%s %x %x"` → `Iface`, `Destination`, `Gateway` (первые три колонки; остальные не нужны). Формат колонок — `Iface Destination Gateway Flags RefCnt Use Metric Mask ...`.
10. Default route — строка, где `Destination == 0`. У неё `Gateway` (hex, host-byte-order, см. ловушку 2) — это IP шлюза, `Iface` — через какой интерфейс.
11. Перевести gateway-число в строку IP: положить в `struct in_addr` и `inet_ntop` (следи за byte order — тут и проявляется ловушка 2, проверь результат против `ip route` / `route -n`)
12. Сшить: для интерфейса с именем `X` печатать gateway, если в таблице default route идёт через `Iface == X`; иначе `(no gateway)`.

## Примеры для теста

- **Тест 1** — базовый прогон, сверить с системой — `./ifenum` и рядом `ip -4 addr show` (IP+маски совпадают?) и `ip route` (gateway совпадает?).
- **Тест 2** — endianness gateway — сравнить твой распечатанный gw с `route -n` (колонка Gateway). Если получилось «задом наперёд» (напр. `1.0.168.192` вместо `192.168.0.1`) — ловушка 2 не отработана.
- **Тест 3** — фильтрация не-IP — на машине с активным Wi-Fi/докером посмотреть, что интерфейсы без IPv4 (или чисто L2) не роняют программу и не печатают мусор. Проверить `lo` (у него gateway нет → `(no gateway)`).
- **Тест 4 (edge)** — запуск в окружении без default route (напр. чистый network namespace `sudo ip netns exec ...`) — программа не должна падать, просто у всех `(no gateway)`.

| 1 | Каст `(struct in_addr *)p->ifa_netmask` → `s_addr` читает `sin_family`+`sin_port` (offset 0..3), а не адрес (offset 4). popcount(2)=1 → маска всегда `/1` | crit | исправлено (каст в `sockaddr_in` + `.sin_addr.s_addr`) |
| 2 | `/%c` печатает символ с кодом 24, а не «24»; `mask_bit` был `char` | crit (неверный вывод) | пользователь исправил сам (`int` + `%d`) |

| 4 | `ifa_netmask == NULL` не проверен → потенц. разыменование | edge | пользователь добавил guard сам |
| 5 | `fprintf(stderr,"no addr")` на каждый не-AF_INET узел → спам (IPv6/MAC узлов много) | средний | исправлено (молчаливый `continue`) |
| 6 | `fopen("/proc/net/route")` внутри цикла по интерфейсам — файл перечитывается N раз | средний | оставлено осознанно (работает, риск/цена низкие) |
| 7 | `sscanf` без проверки возврата — на кривой строке `iface`/`dest`/`gw` держат старьё | средний | оставлено осознанно (формат `/proc` стабилен) |

**Security-заметки:**
- **Type punning `sockaddr` → `sockaddr_in`** безопасен только после проверки `sa_family`; каст в неверный
  тип (`in_addr`) читает не те байты из-за смещения полей — не падение, а тихо неверный результат.
- **`%15s` в `sscanf`** обязателен для `char iface[16]` — иначе overflow (класс `gets`).
- **Печать untrusted-строк** (имена интерфейсов из ядра здесь доверенные, но привычка): в этой задаче
  санитизация не делалась — источник локальный (ядро), не сеть.

## Ключевые термины (English)
- **interface enumeration** — перечисление интерфейсов и их параметров.
- **`getifaddrs` / `freeifaddrs`** — API списка адресов всех интерфейсов + освобождение.
- **socket address polymorphism** — `struct sockaddr *` как общий тип; реальный по `sa_family`.
- **prefix length / CIDR** — длина маски в битах = popcount единиц.
- **routing table / default route / gateway (next hop)** — таблица маршрутов; `0.0.0.0/0` = выход наружу.
- **host vs network byte order** — LE в CPU vs BE в сети; `/proc`-hex = host-order слово.
